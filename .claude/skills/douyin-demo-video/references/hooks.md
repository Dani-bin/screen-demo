# 开头 3 秒：口播和画面

抖音用户划走只要一秒。这一系列视频的规矩是：**前 3 秒直接把这个 demo 最好看的效果演出来，口播第一句说结果**，痛点、背景、技术都往后放。
这条规矩来自用户的一次退稿（2026-10-17，院内导航）：初版开头先讲"去医院最怕找不到科室"，镜头在 1F 走廊里游走，用户看完说"视频开头并不吸引观众"，改成路线从南门一路长到 3F、终点针落下才通过。

## 先找"招牌效果"

写口播之前，先在页面里找出这个 demo 的招牌效果，开头 3 秒就拍它。好的招牌效果要满足：

1. **只有这个 demo 有**：换到别的大屏上就不成立（"路线从大门长到三楼诊室"可以，"镜头绕场景转一圈"不行）。
2. **有一个看得见的变化，能在 2.5–3 秒内从开始演到高潮**：路线长出来、终点针落下、诊室亮起来、光柱冲起、扫光把卫星图变成成品。慢慢加载、缓慢环绕这种没有"那一下"的不算。
3. **在手机上看得清**：横版视频在竖着拿的手机上只有屏幕宽，主体要占画面一半以上；靠面板里小字才看得懂的效果不适合开头。
4. **能用一句大白话说出来**，而且这句话就是开头的口播。

一般列 2–3 个候选，在页面里实际看一遍（in-app 浏览器截几张），推荐一个，在口播确认关卡里让用户一起看。

## 开头口播怎么写

- **第一句说结果，不说过程**：用户看完这一句就知道"这东西能干嘛、厉害在哪"。
- **和画面说的是同一件事、同一时刻**：念到"亮起来"时诊室正在亮，念到"一步不绕"时路线正好到终点。画面和口播各说各的，钩子就散了。
- **短**：≤ 16 字，按 5 字/秒 3.5 秒内念完（`build.py --plan` 会检查）。长了就把最抓人的词挪到最前面。
- **具体**：有地点、有数字、有对象（"三楼核磁共振室""三分钟""整间诊室"），不说"非常智能""很炫"。
- **痛点放第二句**：「普通叫号屏只有一排红字，前面还有几个人，全靠猜。」紧跟在钩子后面，正好解释钩子为什么值得看。

几种好用的句式（往期都用过）：

| 句式 | 例子 | 适合 |
|---|---|---|
| 结果 + 数字 | 从医院大门到三楼核磁共振室，三分钟，一步不绕。 | 有明确起止、可量化的功能（导航、调度、巡检） |
| 场景 + 视觉奇观 | 医院就诊叫号，整间诊室会亮起来。 | 有一个"亮起来 / 动起来"的高亮效果 |
| 反差对比 | 别人做项目靠图纸，我做项目，靠一张卫星截图。 | 输入很少、产出很多（真实数据、卫星图生成） |
| 身份反转 | 这次不给老板做大屏了，我用 AI 把老家搬进了电脑里。 | 题材和往期不同的一期 |
| 前后对比 | 以前做一个炫酷大屏要好几天，现在 AI 一天就搞定了。 | 讲效率；画面上能放"以前 / 现在"两个状态 |

不要用：

- 打招呼和预告：「大家好」「今天给大家分享一个……」「先别划走」。
- 先讲痛点或背景：「去医院最怕……」「随着智慧医疗的发展……」——这是第二句的内容。
- 泛泛的问句：「你知道数字孪生吗？」
- 技术名词开头：「基于 Three.js 和 Blender……」——技术栈写在描述里，口播中段一句带过即可。

## 开头画面怎么拍

- **第 0 帧就是成品画面**：不要黑场淡入、加载遮罩、logo、标题卡，不要从空白页开始。分镜的 setup 里把镜头、面板摆好，preroll 快进到效果即将发生前约 0.3 秒才开录。
- **0.3–0.5 秒内画面开始变化**，2.5–3 秒演到高潮（终点针落下、光柱冲满、扫光扫完），开头这段画面一般 3–4 秒。
- **主体够大**：能全屏三维就全屏三维（藏掉侧栏，`REC.hide(...)`），或者推近到效果所在的位置。候诊叫号那条开头带着两侧面板，被叫诊室在手机上只有指甲盖大，是能做得更好的地方。
- **镜头动 + 物体动**：至少有一样在动，最好两样都有（镜头飞进诊室的同时地面变色）。
- **颜色要跳**：招牌效果通常就是页面里的强调色（橙色路线、橙色叫号），开头那帧里它要最显眼。
- 口播第一句结束的那一刻，画面停在效果最完整的状态，第二个镜头再切。

## 检查（录完必做）

`build.py` 组装完会写 `hook-sheet.png`：成片 0–3.5 秒每 0.5 秒一帧，下面印着当时正在念的字幕。逐条对：

- [ ] 0.0 秒那帧已经是好看的成品画面（不是黑的、白的、加载中、面板没出来）
- [ ] 0.5 秒那帧和 0.0 秒已经有看得出的变化
- [ ] 3.0 秒前效果演到了高潮
- [ ] 每一帧下面的字幕说的就是那一帧画面里正在发生的事
- [ ] 把图缩到手机宽度（约 400 像素宽）看，主体还认得出来
- [ ] 开头那句 3.5 秒内念完（`build.py --plan` 的"开头那句……秒念完"）

有一条不过就改分镜重录开头那段（只重录这一段：`rec.mjs <分镜文件> <url> <分镜名>`），别指望后期补救。
