## 规划要点（v1）

- 客货分流：北口小车出入口（右进右出，场内环行），中部重卡入口，南端重卡出口；门前靠场地一侧是南行车道。
- 小车区（北侧宽段）：加油加气站（汽油 / 柴油 / CNG）→ 乘用车换电站沿路排布；罩棚西侧是埋地油罐和 CNG 储气；办公楼 3F（便利店 + 司机之家）放在西北角，楼前有员工车位 ×6 和私家车位 ×8。
- 重卡区（南侧窄段）：LNG 加气站沿路；西侧是重卡超充位 ×10，上方加光伏车棚；箱变和配电房在两区交界处；LNG 储罐在南端尖角。
- 罩棚和重卡车棚顶上加光伏；储能只做预留。
- 安全间距未按 GB 50156 专业复核。

## AI 概念图与规划 v1 不一致的地方（v1 时以规划为准，v2 已改为以设计稿为准）

- 地块被画成了胶囊形，实际是水滴形，北宽南窄。
- 重卡超充位画成了垂直式，规划是 60° 斜列。
- 02 里画了实体储能柜，规划中储能只是预留。
- 01 里私家车位挤在北端，规划是放在办公楼前和回程车道边。

## 实现（2026-10-12）

- 建模：`scripts/blender/energy/`（Blender 脚本，布局读 `site.json`），导出 `public/energy/station.glb`、`vehicles.glb`
- 页面：`src/views/energy/`；开场「现状航拍 → 规划」动画，之后进入仿真运营态，顶栏「规划回顾」可重播

## v2：完全按设计稿还原布局（2026-10-12）

v1 照规划草图建模，结果和用户确认的设计稿 01 对不上（沿路顺序左右颠倒、地块形状、重卡位排法、办公楼位置都不同）。v2 推翻 v1 规划，改为**从设计稿反求布局**：

1. **标定相机**：设计稿里罩棚屋面、车位前沿、车棚前沿都是地面上的矩形 / 直线。对它们的像素角点做最小二乘拟合，
   得到设计稿的相机：近似正交，方位约 43°（相对门前国道）、俯角约 24°，比例 8.33 px/m（以加油罩棚长 40 m 定尺度），残差约 3 px。
2. **反投影**：把每栋建筑、道路、沙盘边缘的像素点按标定相机反投影回地面（屋面点按估计高度），得到规划米坐标，
   写进 `scripts/energy/draw_plan.py`（v2 数据段的注释里有对应关系）。
3. **页面镜头对齐**：`scene/theme.js` 的 `camera`（方位 -47.06°、俯角 23.66°）与 `view`（锚点 + 像素 / 米）直接用标定结果，
   三维画面与设计稿在整屏效果图里的位置逐像素对齐，不再按包围盒自适应。
4. **叠图核对**：`node scripts/energy/capture.mjs <dev 地址> <png> --clean` 截页面（镜头固定在主视角、隐藏面板），
   `python3 scripts/energy/compare.py <png>` 输出 设计稿 | 实现 | 边缘叠图（品红 = 设计稿、青 = 实现）三联图和半透明混合图；
   Blender 里用同一相机渲染的预览图加 `--raw` 也能比。光影按区域取平均色和设计稿对比（站坪、路面、树林、屋面……）逐项调到接近。

设计稿与甲方清单 / 常理冲突时的取舍：

- 设计稿画了 12 个重卡位，甲方要求 10 个——保留 10 个，车位放宽到 6.4 m，整排长度与设计稿一致。
- 设计稿没画储能、配电房——不再预留储能，箱变只做设计稿里的 2 个深灰箱体。
- 设计稿的卫星地块红线（v1 水滴形）已从航拍底图上修补抹掉（`draw_plan.py` 的 `clean_aerial()`，同时写 `public/energy/site.webp`）。
- 重卡充电改为「牵引车 + 厢式挂车」倒车入位（设计稿车位里是整车），挂车领先沿曲线拐进车位（`scene/vehicles.js`）。

| 区域 | 设计稿实测平均色 | 做法 |
|---|---|---|
| 加油站坪 | 暖白（约 136,107,91） | 罩棚灯面与烘焙面光改暖白；页面里罩棚面光强度压到 1.5（它在湿润地面上的高光会把站坪刷白） |
| 罩棚屋面 | 光伏深蓝（约 60,83,121） | 光伏几乎铺满屋面，只留 1.2 m 白边；屋面板改中灰 |
| 树林 / 远山 | 偏蓝的墨绿（约 5,19,30） | 叶片、针叶、林下草地改蓝黑调；远山与村庄加雾隐入夜色 |
| 加油罩棚檐口 | 青蓝色光边 | 新材质 `M_led_canopy`（加油机顶部仍是橙色） |
| 光伏屋面 | 映着天空泛蓝 | 实时环境反射太弱，给 `M_pv` 加一层均匀蓝色自发光（`THEME.pvSheen`） |
| 便利店 / 办公楼 | 暖光玻璃 | 橱窗贴图改暖白、降亮度；去掉女儿墙青色灯带 |
| 远山 / 村庄 | 深蓝灰（约 14,24,37），村庄窗光透出 | 雾色改深蓝灰，坡面改蓝灰；村庄窗光单独材质、不受雾影响 |
| 车位前通道、停车场 | 成片暖色光斑 | LNG 罩棚东北角、车位前沿、停车场补路灯，车棚补光加强；停车场停满（白 / 银 / 黑为主） |

最终实测（页面截图与设计稿同区域平均色之比）：加油站坪 1.10、罩棚下 0.94、LNG 站坪 0.92、国道 0.89、车位前通道 1.10、
办公楼 0.92、光伏屋面 0.94、远山 0.96、停车场 0.83（随停放车辆颜色浮动）。

### 开场动画

航拍截图本身只有约 447 × 370 m，开场俯视镜头斜着看时屏幕角落会露出截图外的黑底。现在 `draw_plan.py` 把截图四周镜像外扩 32%
（越往外越模糊、越暗，最外一圈渐隐到背景色），开场俯视改为国道横在画面下方、场站居中的对称视锥，倾斜时再转到设计稿视角。

### 页面构图

设计稿视角下场站沿对角线斜穿画面，设施已经横向占满左右面板之间（价格立柱 ↔ LNG 储罐），整体放大会钻到面板下面，
换更平的视角试过（方位 -53° / 俯角 30°、-60° / 36°）也只会让场站更小，左下角的三角空白依然在。所以保持设计稿视角，
页面上整体下移 28 px（`THEME.viewShift`，叠图对比时 `capture.mjs --design-frame` 归零），空闲摆动幅度从 ±10° 收到 ±6°
（两端不再转到面板下），左下角空白放「场站规模」速览卡（`components/SceneLegend.vue`，各设施颜色与三维灯带一致）。
