## 地理事实（子代理配准，置信度高）

- 位置：营山县城西侧五通村，小河西岸、主路北侧。我家约 31.091797 N, 106.553624 E，海拔约 334 m。
- 比例 **0.410 m/px**，截图约 319 × 264 m；红线范围约 302 × 231 m，**4.85 公顷**。
- 截图是旋转视角：图像"上" = 真方位 73.58°，**真北在图中左上**（从图像上方顺时针 286.4°）。
- 高差约 17 m：左上角树林最高（≈339 m），右侧水渠最低（≈322 m），我家在缓坡脊上，中部大田是浅洼（≈327 m）。DEM 精度约 30 m，只定大势。
- 我家正面朝图像下方（真方位约 254°，西南偏西），对着大田；夏日傍晚太阳从图像左下方来，照亮正立面，与照片光线一致。

## 已定方案

1. **页面**：新路由 `/hometown`，加入 `/home` 轮播。标题"营山 · 五通村"，副标题"老家记忆"；卡片简介"四川营山五通村，按卫星图与老照片还原的四季沙盘"。显示真实地名。
2. **风格**：精致微缩沙盘，写实材质（白色条形瓷砖、红瓦、青瓦、蓝色彩钢瓦、水泥院坝）。先用 AI（Figma generate_image）出 1–2 张效果图定调，确认后再建模。
3. **流程**：沿用 `/energy` 的做法：Blender 脚本建模 → Cycles 烘焙地面光照 → GLB → three.js。
4. **年代**：2017 年夏天。房屋和田块按 2017 影像来，我家按照片来；影像里没有的不加，后来拆了的不删。
5. **范围**：只做红线以内。红线处切开，形成沙盘边缘，露出土层截面；四周是虚化的背景。
6. **地面**：以卫星图为描图底稿，把地物重建成 3D，卫星图本身不显示。
   - 地物：坡上的柏木林、慈竹丛，西北片老房子和菜地，中部大块水稻田，西南的旱地和梯田坎，东侧小加工厂（蓝色彩钢顶 + 白色大屋顶 + 料堆），水渠，南侧水泥公路及临街房屋，西南角带院坝的人家。
   - 地形：按高程数据定大势，**竖向放大 1.5 倍**；再按卫星图手工加田坎、梯田、房屋台地和台阶。
7. **我家**：照片里能看到的都还原：三开间三层，白色条形瓷砖，二、三层阳台宝瓶栏杆，一层门洞，两个红灯笼，对联，门楣上的牌匾，阳台上的卫星锅，防盗窗，左侧枇杷树，门前台阶和院坝。照片里的人不做。看不到的侧面和背面按同样的瓷砖和窗型推测补全。卫星图上的轮廓按推测补一间一层红瓦偏房。
   - **屋顶**：照片是平顶 + 挑檐，卫星图上是红褐色坡顶。推断为三楼平顶上**退后加盖了一层红瓦坡顶**，前面露出一块白色平台。
8. **其它房子**：每张参考照片做成一个参数化原型（层数、开间、阳台、屋顶、外墙材质可调）。按卫星图上的屋顶颜色决定原型，同一类里随机组合层数、开间、瓷砖颜色（白 / 米黄 / 粉）、裙砖、偏房和彩钢加建。

   | 蓝色 | ref/02 白瓷砖二层 + 红琉璃瓦檐 + 楼顶蓝色彩钢棚；ref/06 米黄三层 + 彩钢顶 |

9. **季节与时间**：**暂时只做夏季**（稻田翠绿；2026-10-12 用户把四季缩减为夏季，其它季节以后再说），保留昼夜切换（夜里窗户亮灯），默认是盛夏傍晚。
10. **开场**：
    1. 从正俯视的卫星图开始（老照片质感）
    2. 地块"长"成 3D，镜头倾斜、环绕一圈
    3. 推近我家，停在和照片相同的机位和构图，淡入原始照片作对照
    4. 之后自动环游，可以自由转动
11. **界面**：标题、昼夜切换、"我家"一处标注、推近我家时弹出老照片卡片（文字先写占位，如"建于 20XX 年"）。**不做数据面板。**
12. **活物与细节**：傍晚炊烟，夜里窗灯和红灯笼，电线杆和电线，竹子和树随风摆动，水渠和水田的水面，几只鸡鸭、一条土狗。**不做村民。**
13. **环境音**：夏季音效，随昼夜切换（白天和傍晚是蝉鸣、鸡叫，夜里是蛙声和虫鸣）；默认静音，带开关；用免版权素材。

### 田埂路（2026-10-12）

用户要求按地图识别田埂，每块田都要有路可走。卫星图分辨率约 0.2 m/px，只能看清一部分分界：西侧的斜条田块、三条田间小路、各地块边界。大田内部看不出线，自动检测（Hessian / Gabor 细线、两期影像颜色分区）也找不到可靠的连续线。

所以 `draw_plan.py` 的 `FIELD_BUNDS` 用两种来源：
- 看得见的照描。
- 大田内部推断：方向和中间斜路平行，再参考色块分界，每块田约 25–40 m。

田埂和小路、回家路线连成一张网，每块田都走得到。

三维里的做法：
- `build_site.py` 按顶点到田埂折线的距离算出 `bank` 权重：中线为 1，1.3 m 外降到 0。
- 材质按权重分三档：中线是土路，两侧是草，再往外是稻田。稻株避开田埂。
- 草图 `plan-v1*.png` 上用绿边白芯的线标出了田埂。
