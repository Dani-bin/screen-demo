# 03 场景收敛与设备编号

> 选定具体的空间范围，给每个对象一个稳定编号。之后模型节点、测点、图表、事件只用编号指代对象。对象清单同时写进 `devices.json`。

## 范围

一句话：呼伦贝尔莫日格勒河中游一片真实草原（12 × 10 km 沙盘）上，一个虚构的合作社牧场在 7–8 月夏秋放牧期的**划区轮牧与畜群监管**。

- **牧场**：莫日格勒河示范牧场（虚构，不对应任何真实合作社）。
  - 暖季草场约 9.3 万亩，其中轮牧分区约 8.5 万亩，河岸禁牧保护带约 0.77 万亩。这是 `prepare.py` 按真实河道排出来的结果，最初预估是 10.2 万亩。
  - 设 10 个轮牧单元：7 个养羊、3 个养牛。每个单元 4 个分区，共 40 个分区。
- **存栏**：羊 5400 只，分 7 群；牛 380 头，分 3 群。合计 7300 羊单位（1 头牛 = 5 羊单位，见 02 调研）。
- **项圈**：
  - 羊按群管理，每群 3 个项圈戴在头羊上，共 21 个。
  - 牛每头一个项圈，共 380 个。
  - 全场合计 401 个。
- **季节作业**：7–8 月是夏秋放牧抓膘期，还要做药浴、冬羔母羊配种（02 调研）。一天的节奏：
  - 白天在分区内放牧。
  - 中午到饮水点饮水。
  - 傍晚羊群回营地夜宿；牛群留在分区。

## 空间与流程关系

```
轮牧单元 Uxx（4 个分区 Uxx-1…4）
   ├─ 当前放牧分区 ← 畜群（羊群 SF / 牛群 CH，项圈定位）
   │      ↓ 中午                          ↑ 次日清晨出牧
   │   饮水点 WP（机井 + 光伏提水 + 水槽）   │
   │      ↓ 傍晚（羊群）                    │
   │   牧户营地 HH（住房 + 棚圈 + 夜宿圈）─┘
   └─ 其余分区：休牧恢复 → 长势达标后转为待牧 → 下一次转场

场部 HQ-01：称重通道 WS-01、药浴池 DP-01、储草棚 HS-01（集中作业时畜群赶到这里）
通信：项圈 → 太阳能中继基站 BS → 平台；视频：摄像头 CAM（场部、重点饮水点）
河岸禁牧保护带 RB-01：沿莫日格勒河两岸，畜群进入即算越界
```

## 对象清单

编号规则：编号就是模型节点名（三维里的 Object 名），找不到就报错。分区、畜群这类程序化生成的对象也用编号命名。

| 编号 | 名称 | 类型 | 数量 | 模型节点名 | 备注 |
|---|---|---|---|---|---|
| U01 … U10 | 轮牧单元 | unit | 10 | U01 … | U01–U07 养羊，U08–U10 养牛 |
| U01-1 … U10-4 | 轮牧分区 | paddock | 40 | U01-1 … | 多边形，状态：放牧中 / 休牧恢复 / 待牧 |
| RB-01 | 河岸禁牧保护带 | reserve | 1 | RB-01 | 沿河两侧约 150 m |
| SF-01 … SF-07 | 羊群 | flock | 7 | SF-01 … | 每群 700–850 只，按群显示 |
| CH-01 … CH-03 | 牛群 | herd | 3 | CH-01 … | 每群 110–140 头，可显示到单头 |
| CH-01-001 … | 单头牛 | cow | 380 | 实例（InstancedMesh 下标） | 编号 = 牛群 + 三位序号 |
| CL-0001 … CL-0401 | 项圈 | collar | 401 | 不单独建模 | CL-0001–0021 戴在头羊上，其余对应单头牛 |
| WP-01 … WP-16 | 饮水点 | water | 16 | WP-01 … | 机井 + 光伏提水 + 水槽；测水位、流量、泵状态 |
| HH-01 … HH-10 | 牧户营地 | homestead | 10 | HH-01 … | 一个单元一户：住房、棚圈、夜宿圈 |
| HQ-01 | 合作社场部 | hq | 1 | HQ-01 | 子对象 WS-01 称重通道、DP-01 药浴池、HS-01 储草棚 |
| BS-01 … BS-04 | 太阳能中继基站 | station | 4 | BS-01 … | 覆盖半径约 5 km（假设） |
| CAM-01 … CAM-08 | 摄像头 | camera | 8 | CAM-01 … | 360° 全景，场部 2 个，饮水点 6 个 |
| HD-01 … HD-10 | 放牧员 | herder | 10 | HD-01 … | 手持终端定位，一个单元一人 |

以上对象各自在三维场景里的位置，由 `scripts/smart-ranch/prepare.py` 按真实地形和影像生成到布局数据：

- 单元和分区避开河道、湿地和陡坡。
- 饮水点放在离河远的分区。
- 营地放在单元里靠路的缓坡。

## 每块看什么

| 对象 | 需要查看的内容 | 帮使用者判断 |
|---|---|---|
| 轮牧分区 | 真实 NDVI 长势、可食草量（示意）、已放牧天数、剩余可牧天数、休牧天数 | 这片草还能吃几天；下一块该轮到哪 |
| 轮牧单元 / 全场 | 草畜平衡指数（实际载畜量与合理载畜量之差）、各状态分区数 | 是否超载；哪个单元压力最大 |
| 羊群 / 牛群 | 位置、头数、今日行走、在线项圈数、所在分区 | 畜群在哪；有没有离群、走失 |
| 单头牛 / 项圈 | 位置、电量、最后上报时间、信号 | 谁越界了；哪个项圈要换电或检修 |
| 饮水点 | 水位、今日供水量、泵状态、光伏发电 | 哪个饮水点没水或该修 |
| 河岸保护带 / 电子围栏 | 越界事件、越界畜群 / 牛的轨迹 | 越界的牲畜去哪找、派谁去 |
| 场部 | 称重（日增重）、药浴进度 | 抓膘效果、药浴是否按期 |
| 基站 / 摄像头 | 在线状态、覆盖范围 | 定位数据过期是因为设备还是牲畜走远 |
