# 05 需求方案

## 画布与适配

- 设计尺寸 1920×1080，和仓库其它页面一样用 rem 等比缩放（`postcss-pxtorem` + `amfe-flexible`）。
- 现场屏：作品合集展示用，按常见 16:9 单屏（1920×1080 / 3840×2160）考虑，没有拼接屏。
- 主机：普通带独显的电脑或笔记本，浏览器全屏；性能预算见实现阶段。

## 时间设定

- 大屏设定在 **2026 年夏秋放牧期**。真实日期映射到 2026-07-01 … 08-31 的某一天（按一年中的第几天对 62 取余）。时刻用真实的北京时间，墙上的钟和屏上的一天节奏一致（`sim/simulator.js` 的 `demoTime`）。
- 草场长势用 2026 年 4–10 月真实的 Sentinel-2 逐月 NDVI；同比用 2025 年同月。

## 三维场景

- **必须出现的对象**（编号见 `03-scope.md`）：
  - 10 个轮牧单元、40 个分区
  - RB-01 保护带
  - 7 个羊群、3 个牛群（380 头牛可见到单头）
  - 16 个饮水点
  - 10 个营地、HQ-01 场部
  - 4 个基站
  - 告警对象
- **镜头**：
  - 主视角：整个沙盘斜俯视，河谷横贯画面。
  - 单元视角：约 3 km 范围。
  - 近景：约 800 m，看得到营地、饮水点的三维模型和畜群。
  - 告警联动镜头：对准事发对象。
- **数据驱动的动效**：
  - 畜群按仿真位置移动：羊群是一团点云加头羊标记，牛按单头显示。
  - 今日轨迹线逐渐延长。
  - 饮水点液位环。
  - 告警对象的光柱和扩散环。
  - 越界时电子围栏（保护带边界）亮起。
  - 长势图层按月份过渡。
  - 自动巡游。

## 状态

| 状态 | 呈现 |
|---|---|
| 正常 | 分区按长势着色（褐 → 黄 → 绿）或按轮牧状态着色；畜群标记常亮 |
| 告警 | 告警对象红 / 橙光柱 + 扩散环；保护带边界闪烁（越界）；告警列表置顶，处理状态随时间推进 |
| 数据过期 | 离线项圈：标记变灰，显示"最后上报 2 小时前"；所在畜群的在线项圈数减少 |
| 质量不确定 | 读数旁加"?"，数值灰显（例：饮水点流量计偶发不确定） |
| 夜间 | 羊群回营地夜宿，牛群卧息；沙盘整体压暗（按北京时间的时刻） |
