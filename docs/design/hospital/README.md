# 医院院内导航 demo · 模拟医院 CAD

病人到医院找不到科室、检查室；即使知道在哪栋楼、哪层、哪个房间，也要花时间找。
本 demo 在大屏上演示院内导航：自己选起点和终点 → 规划跨楼层路线 → 明确提示走楼梯、电梯还是扶梯 → 人员模拟从起点走到终点。
**不做真实定位**，医院是虚构的。

流程（用户定的顺序）：**先出模拟医院的 CAD 图 → 用户确认 → 再出设计稿 → 用户确认 → 实现页面。**
当前阶段（2026-10-16）：CAD 已定稿；用户选定**设计稿 v1 浅色版**（`01-draft-light.png`）；页面 `/hospital` 已实现。
按"方向定了就按推荐推进"的约定，采用了建议规则：**设计稿只定风格，房间布局、扶梯朝向、路线以 CAD 为准**（用户未表示反对，若要改成照 AI 图布局需另行确认）。

## 我（Claude）定的细节 —— 请在看图时一并核对

- **每层房间的具体安排**（见各层图右侧的房间表）。外圈除 20 个目的地外，剩下的位置做成辅助用房（办公、库房、处置室、污洗间等，灰色斜线），图上标明"不作导航目的地"。
- **CT、核磁放在 3F**：真实医院一般放 1F 或地下（设备重），这里为了 3F 集中展示医技检查。放射类房间不开外窗。
- **扶梯做成交叉式**：4 条梯并排横跨中庭（南北走向）。1F↔2F 下端在中庭南侧，2F↔3F 下端在中庭北侧，所以 2F 出扶梯后掉头几步就能换乘继续上楼。⑦ 轴在中庭两条长边上的两根柱子落在扶梯之间，按大跨度梁处理去掉了。
- **耗时参数**（`scripts/hospital/nav.py`）：步行 1 m/s；扶梯每层 20 s；电梯候梯 60 s（门诊高峰）+ 开关门 6 s + 每层 4 s；楼梯每层上 38 s / 下 26 s（含病人爬楼的体力折算）；每转一次弯加 4 s，等长路线优先选拐弯少的。
  效果：跨两层一般推荐扶梯；靠近东西两端、只差一层时推荐楼梯；目的地在电梯附近时推荐电梯。
- 1F 大厅设导诊服务台和自助机；2F 有内科 / 外科分诊台；2F、3F 中庭北侧有护士站。

"大屏 + 手机同屏"里的手机画面这一版没放（用户后来只提大屏导航），需要的话再加。

**AI 三维图和 CAD 对不上的地方（确认前请定规则）：**
- 房间：AI 图每层四周是一圈均匀的小房间，数量、开间都和 CAD 不同（CAD 每层 20 个目的地 + 辅助用房，3.6 m 模数）。
- 扶梯：浅色图 4 部（与 CAD 一致），深色图只有 2 部；两张图里 3F 都在中庭北侧下梯，CAD 是交叉式布置、3F 在南侧下梯，所以三维图里 3F 的路线直接沿北侧走，底部小图按 CAD 算的是「南走廊 → 东走廊 → 北走廊」。
- 科室：AI 图 1F 急诊（红）在西侧，CAD 在东南角；2F 画了核磁 / CT 设备，CAD 里放射科在 3F。
- 一致的部分：三层拉开的爆炸视角、主入口在南面正中、电梯在中庭北侧、东西两端楼梯、目的地在东北角。
- 建议规则：三维图只定风格（配色、材质、视角、路线与标注的表现方式），房间布局、扶梯朝向和路线以 CAD 为准，实现时三维模型按 CAD 建。

## 页面实现（2026-10-16）

- 路由 `/hospital`，页面 `src/views/hospital/`：`index.vue`（版式按 v1：左栏选点、中央三维、中下分层小图、右栏导视牌 + 分步）、`route.js`（nav.py 的 JS 版，两边分步文字逐字一致）、`scene/HospitalScene.js`（程序化三维）、`scene/theme.js`（配色尺寸）。
- 三维不走 Blender：直接用 `plan.json` 的同一份 CAD 图元挤出（墙剖到 1.5 m、家具矮块、楼梯实心踏步、扶梯按真实坡度、电梯玻璃井贯通三层）；三层按爆炸图拉开 24 m（俯角 24°，层间距要大于楼板进深的投影，上层才不挡下层）。
  不用实时阴影（叠着的楼板会把下层整片压黑），角落暗部交给 GTAO；路线带、人员、地图针放在 GTAO 之后的叠加层里画。
- 交互：左栏点选 / 搜索设终点，点"起点"行后再点地点设起点，可交换；三维里点房间地面设终点；推荐 / 无障碍切换；点分步提示让人员从那一步接着走；闲置 40 秒后到达即轮播下一条演示路线。
- 人员模拟用演示时间（步行 4.2 m/s、扶梯斜段 4.5 s……见 `THEME.sim`），面板上的"剩余约几分钟"按路网真实代价换算。
- 首页已登记（`demos.js` 末尾，分类"智慧医疗"）。预览图 `public/home/hospital.webp` 暂时用的是设计稿 v1；沙箱里起不了无头 Chrome，需在本机运行 `node scripts/capture-home-previews.mjs <开发服务器地址> hospital` 换成真实页面截图。
