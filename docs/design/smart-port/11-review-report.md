## 冲突取舍（本阶段新增）

- 竖向夸张 1.52：岸桥、轨道吊、箱堆、AGV、建筑、告警光柱以码头面为基准拉高，船以水线为基准拉高；平面布局仍是真实尺寸。
- 镜头俯角固定 40°、视场角 12°：只靠岸线上的点定不住俯角，按定稿告警圆环的扁度和评审意见取；泊位刻度 + 岸桥牌残差 RMS 6.8 px（含权重 0.3 的估计点），略超 5 px。
- 雾和近裁剪面随镜头距离变化（总览在 6.5 km 外）。
- 搜索框占位文字保留"箱区"：仿真里没有箱号数据，写"箱号"会误导。
- 作业路表默认按岸桥编号排、标签写"按岸桥"：定稿的行就是按编号排的，"按效率"只是占位字；点一下切到"按效率"（从低到高，停机和瓶颈在前）。
- 告警表标题栏"全部 ▾"做成筛选（全部 / 未结束 / 重要）。
- 本周航次卡去掉标题栏里的总数（定稿没有）。
- 角标：定稿源码里 `.corner.tl` / `.tr` 和时间轴 `.tl`、进度条 `.tr` 同名，左上 / 右上角标被挤到卡片底部、占了一行。页面把角标画回四角，非拉伸卡底部补上同样的 24 px，卡片高度和定稿一致。
- 总览时岸桥牌只标"在作业岸桥最多的那条船"（定稿标的是长澜云帆的 QC14–QC18）；跟踪某条船时标它的，近景标全部在作业的。
