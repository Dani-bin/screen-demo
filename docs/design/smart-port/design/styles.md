# 设计稿风格候选

> 阶段 5 产出。做法见 skill 的 `references/design-drafts.md` 第 2 节：先用 ui-ux-pro-max 检索，组成 3–4 个真的不同的候选，推荐项放第一个；用户用选择题选定一种后（拍板点②）才出设计稿，且只出一版。
>
> 背景：2026-10-21 第一轮出了三套（A 海图日间 / B 夜班钠灯 / C 晨雾单船跟踪，`v1-a/b/c.png`）。用户的反馈是"都不行，整个大屏界面看着一点都不炫酷，使用 ui 相关 skill 重新设计，只需要出一版"。所以这一轮的候选全部往"炫酷、科技感"走。

## 输入

- **行业与对象**：自动化集装箱码头（洋山四期），包括岸桥、轨道吊、AGV、船舶、箱区。
- **使用者与场所光线**：
  - 码头指挥中心：暗厅，大屏常亮；
  - 作品合集展示：首页聚焦视图是深色。
- **视觉调研参考**：见 `02-research.md` 视觉调研。
  - 国内厂商的主流是"三维铺满 + 两侧暗色半透明面板 + 深蓝青"，例如图扑厦门港 X 光蓝、数字冰雹压暗底图 + 热度、51WORLD 妈湾；
  - 洋山中控塔的真实大屏是俯视方块在流动。
- **ui-ux-pro-max 检索词**：
  - style：`port logistics monitoring dashboard dark futuristic` → `hud-sci-fi-fui`、`cyberpunk-ui`、`dark-mode-oled`、`data-dense-dashboard`；`holographic glassmorphism dark command center` → `glassmorphism`
  - color：`smart port logistics tech dark` → Smart Home/IoT Dashboard（深色科技 + 状态绿）、Logistics（追踪蓝 + 配送橙）

## 版式方向（我的决定，不另问）

**全景型**：中央完整展示整个码头，两侧各区分别解释"船舶靠泊与装卸""自动化设备协同"两条主线。

理由：

- 作品合集首页要一眼看出"这是整座码头"；
- 单船跟踪在需求里本来就是交互，点船后再切换，不需要做成首页版式。

## 候选

### A. 全息孪生 · 深海科技蓝（推荐）· ui-ux-pro-max 风格 id：`hud-sci-fi-fui`

| 项 | 内容 |
|---|---|
| 场景渲染 | **科技全息**：夜色里的码头整体压暗成深蓝实体。<br>岸桥、轨道吊、船体描青色发光边线；AGV 拖着青色光迹在车道上流动；作业路用光带连起"岸桥 → 箱区"。<br>海面是深蓝暗面，带扫描网格和波纹；告警设备升起红色光柱，地面有扩散圆环。 |
| 面板 | 深色半透明底（约 78%），1 px 青色细线框；四角切角，配科技角标与刻度装饰。<br>标题条带流光，数字带轻微辉光；密度高，两侧铺满到底。 |
| 色板 | 底色 #030A16 / 面板 rgba(6,20,40,0.78) / 主色 #19E3FF / 强调 #FFC53D（船舶、跟踪）<br>正常 #2EF2A0 / 告警 #FFB020 / 故障 #FF3B5C / 离线 #5B6B82 |
| 字体 | 标题：阿里妈妈数黑体 / 正文：思源黑体 / 数字：DIN |
| 对应 UI skill | `industrial-brutalist-ui`（终端、蓝图感的数据排版）+ `high-end-visual-design`（发光与层次的克制度） |
| 适合 / 风险 | **适合**：暗厅指挥中心和展示，最符合国内"炫酷大屏"的预期；作业路光带、AGV 光迹能把"协同"直接画出来。<br>**风险**：和 /smart-mine 的深蓝 + 青同色系。用金色强调、海面网格和船舶灯光来拉开；发光只给设备和告警，不满屏光柱。 |
| 实现方式 | three.js 程序化：在现有场景上加边线描光、光迹、光带、扫描海面。工作量最小。 |

### B. 赛博夜港 · 霓虹青品 · `cyberpunk-ui`

| 项 | 内容 |
|---|---|
| 场景渲染 | **写实夜景 + 霓虹**：真实质感的夜间码头，湿地面反光。<br>岸桥挂青色、品红霓虹灯带；箱区顶面有热度色块；远处小洋山的灯火虚化成光斑。 |
| 面板 | 纯黑底，斜切角（八边形）面板，霓虹描边，标题带轻微故障闪动（glitch）和扫描线。 |
| 色板 | 底色 #07060D / 面板 rgba(12,10,22,0.86) / 主色 #00F0FF / 强调 #FF2E88<br>正常 #00F0FF / 告警 #FFB800 / 故障 #FF2E4D / 离线 #6B6880 |
| 字体 | 标题：阿里妈妈数黑体 / 正文：思源黑体 / 数字：DIN |
| 对应 UI skill | `industrial-brutalist-ui` |
| 适合 / 风险 | **适合**：视觉冲击最强，适合抖音和展厅。<br>**风险**：品红和 /waiting 的糖果紫接近；偏游戏感，指挥中心的严肃度弱；写实夜景要更细的模型和灯光。 |
| 实现方式 | three.js + 夜景光照、反射。比 A 多做材质和灯光，工作量中。 |

### C. 黄昏指挥舱 · 暗金玻璃 · `dark-mode-oled` + `glassmorphism`

| 项 | 内容 |

| 色板 | 底色 #0A0A0C / 面板 rgba(18,18,22,0.62) / 主色 #E8B65C / 强调 #4FD1C5<br>正常 #4FD1C5 / 告警 #F5A524 / 故障 #F2555A / 离线 #6E7178 |
| 字体 | 标题：阿里妈妈数黑体 / 正文：思源黑体 / 数字：DIN |
| 对应 UI skill | `high-end-visual-design` |
| 适合 / 风险 | **适合**：领导汇报、访客展示，高级感强。<br>**风险**：暗金和 /building 的金色夜景撞色；黄昏写实最考验模型和材质，程序化模型容易露怯。 |
