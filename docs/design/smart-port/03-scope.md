# 03 场景收敛与设备编号

> 选定具体的空间范围，给每个对象一个稳定编号。之后模型节点、测点、图表、事件只用编号指代对象。对象清单同时写进 `devices.json`（由本文件的编号规则生成）。

## 范围

一句话：上海洋山四期全自动化码头（布局按公开参数和 Sentinel-2 10 m 影像示意，约 ±10 m）在"当天"实时运转中的**船舶装卸进度与岸桥—AGV—轨道吊协同**。

- **码头**：集装箱岸线 2350 m，7 个泊位，61 个垂直于岸线的自动化箱区。
  - 运营全部是模拟的。码头名称和规模用真实公开数据，船名、航线、箱量、设备状态都是虚构的。
- **时间**：码头 24 小时作业，大屏跟随北京时间的真实时钟。没有"白天开工、晚上收工"，只有班次交接（08:00 / 20:00，假设）。
- **主线**：
  - **船舶靠泊与装卸进度**：哪条船在哪个泊位，装卸到哪，能否按时离泊。
  - **自动化设备协同**：每条作业路由"岸桥 → AGV → 箱区海侧轨道吊"串成，看谁在拖慢。
- **不在范围**：
  - 陆侧集卡和闸口的集疏运。闸口只作为场景里的静态建筑。
  - 绿色低碳、安全两条线。风速只作为告警来源和一个小卡片。
  - 一至三期、东海大桥：只作背景。

## 对象清单

编号规则：

- 编号就是三维里的对象名。实例化渲染的设备，用编号到实例下标的映射表，找不到就报错。
- 自西向东编号，与 u 增大的方向一致。

| 编号 | 名称 | 类型 | 数量 | 模型节点名 | 备注 |
|---|---|---|---|---|---|
| B01 … B07 | 泊位 | berth | 7 | B01 … | 沿岸线均分，每个约 335 m；B03、B04 为 7 万吨级，其余 5 万吨级（位置是假设）。B02–B06 可减载靠 20 万吨级大船，大船会跨两个泊位 |
| QC01 … QC28 | 双小车岸桥 | sts | 28 | QC01 … | 共轨，按作业计划移动到船位；主小车、门架小车、吊具是子节点 |
| Y01 … Y61 | 自动化箱区 | block | 61 | Y01 … | 分 11 组：Y01 / Y02–05 / Y06–09 / Y10–15 / Y16–23 / Y24–31 / Y32–39 / Y40–47 / Y48–53 / Y54–60 / Y61；冷藏箱集中在 Y19、Y20、Y31（推断） |
| Y01-S，Y02-S / Y02-L … Y61-S / Y61-L | 自动化轨道吊 | armg | 121 | 同编号 | 每区海侧（S）、陆侧（L）各 1 台，同轨；Y01 单独一个短箱区，只设 1 台，合计 1 + 60 × 2 = 121 |
| AGV001 … AGV145 | AGV | agv | 145 | 实例（InstancedMesh 下标映射） | 状态：空驶 / 重载 / 排队 / 换电 / 故障 |

| DG-01 | 危险品 / 超限箱区 | special | 1 | DG-01 | 西端独立一片（推断）；只显示存箱数和超时告警 |

以上对象在三维里的位置由布局脚本按 u / v 规则生成：

- 泊位、箱区、岸桥轨道、AGV 带、换电站、气象站都按规则计算。
- 箱区的组分界在 Sentinel-2 上核对过：子代理量出的 11 组分界线，落在 10 m 影像上的浅色车道上。
- 箱区长度按影像量出的三档（240 / 310 / 355 m）。

## 每块看什么

| 对象 | 需要查看的内容 | 帮使用者判断 |
|---|---|---|
| 船舶 / 泊位 | 船名、航次、船型、泊位、靠泊时间、计划离泊时间；卸 / 装计划与完成（自然箱、TEU）；作业岸桥数；船时效率；按贝的完成情况 | 能不能按时离泊；要不要加派岸桥 |
| 岸桥 | 作业状态、当前作业船、台时量（自然箱/h）、本船剩余关数、吊具状态（单 / 双吊具）、风速、故障代码 | 哪条作业路慢、是不是岸桥本身的问题 |
| AGV | 位置、状态、任务（哪台岸桥 ⇄ 哪个箱区）、电量、本班任务数、等待时长 | 岸桥下是不是在等 AGV；谁该去换电 |
| 换电站 | 换电中 / 排队的 AGV 数、满电电池数、本班换电次数 | 换电是否成了瓶颈 |
| 轨道吊 / 箱区 | 作业状态、台时量、海侧交换区等待的 AGV 数；箱区堆存量和利用率 | AGV 是否卡在箱区端；哪个箱区太满 |
| 全码头 | 今日吞吐量（TEU / 自然箱）、在泊船舶数、平均船时效率、设备作业 / 待机 / 故障台数、告警 | 今天整体干得怎么样（领导访客） |
| 气象 | 风速、风向、潮位（不显示水深） | 有没有大风停机风险 |
