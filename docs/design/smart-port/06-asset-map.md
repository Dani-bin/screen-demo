## 重组检查

- 面板全部由代码绘制，没有切图，也就没有接缝和透明区域问题。
- 阅读底板：面板底色是 `--panel`（rgba(6,20,40,0.78)），场景两侧和顶部再叠一层压暗渐变（`.vignette`），文字对比度见 README 自查。
- 面板区域和定稿的像素差，在阶段 11 用 `compare.py --panels` 量。
