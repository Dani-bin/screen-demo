# 智慧港口三维大屏：视觉调研报告

这份调研找到 10 个可用参考：国内 8 个，国外只有 1 个（美国 Corpus Christi 港的 OPTICS），另有 1 个洋山四期中控塔的实地报道。鹿特丹、汉堡港务局和 Konecranes / Kalmar 的系统界面没能拿到可用画面，所以国外部分比你列的少（原因见第 5 节）。下面的配色值是从截图里取的近似值。

**几点共性：**
- 国内厂商几乎都是"三维铺满 + 两侧暗色半透明面板 + 深蓝青配色"，船舶进度基本放在面板里（参考 1、4、7）。
- 两种办法能让画面变干净：
  - 减少箱子颜色（参考 3 只用 4 色）；
  - 把底图压灰，只给业务对象上色（参考 4）。
- 洋山的真实调度大屏反而是俯视的抽象方块（参考 9）。

## 2. 三维场景的画法

### 2.1 箱区（几万个箱子不糊）
- 箱子按真实颜色随机着色时，远景会变成彩色噪点（参考 2、4 的截图）；只用 4 色时全景仍然清楚（参考 3）。
- 全景时每个箱区按"贝 × 列"合成实心堆块，高度等于层数，顶面画箱缝线；拉近后再换成单箱的 [InstancedMesh](https://threejs.org/docs/#api/en/objects/InstancedMesh)。**假设**
- 颜色控制在 4 种中性色 + 1 种强调色。强调色只给当前主线相关的箱子，比如被跟踪那条船的装卸箱。**假设**
- 按什么着色：给调度看就按作业状态（待装船 / 进口待提 / 作业中）。不按船公司，原因有两个：
  - 船公司色要 8 种以上；
  - 需求里已定"素色、不用真实涂装"（[需求记录](/Users/zhangjiabin/Desktop/Company/screen-demo/docs/design/smart-port/01-requirements-qa.md)）。
- 堆存密度：在箱区顶面铺一块半透明热度色（参考 4 的做法），只在"堆场"图层打开，不和设备状态色同时出现。**假设**
- 点选箱区时，可以借参考 3 的圆形放大镜，在里面显示 2D 贝位格。

### 2.2 岸桥、AGV 和船舶进度
- **岸桥**
  - 参考 3 只有写实动画，效率数据全在面板里，离开面板就看不出快慢。
  - 双小车岸桥的动画要能看出两段交接：主小车在船和中转平台之间，门架小车在平台和 AGV 之间。吊具升降可以加速 1.5–2 倍。**假设**
  - 岸桥顶上挂一块名牌：编号 + 本船剩余关数。**假设**
- **AGV**
  - 全景时把 145 台画成带短尾迹的小方块，和洋山中控塔大屏的读法一致（参考 9）。
  - 颜色只表示 3 种状态：重载 / 空驶 / 去换电。电量用车顶一根细条，低于 25% 变色（阈值是之前业务调研里的**假设**）。
  - 路径光带只画选中船和告警车的那几条，不画全网。**假设**
- **船舶进度**
  - 已有两种做法：图扑把船画成剖面，每个舱一格，配一张完成率表（[参考 1 同文图11](https://www.hightopo.com/blog/6003.html)）；易知微用船形图标进度条（参考 6）。
  - 建议直接画在船体上：甲板箱从船头到船尾按贝分已完成 / 作业中 / 待作业三色。进入单船跟踪后，展开成逐贝的横剖面图（[行箱位图的画法](https://en.wikipedia.org/wiki/Stowage_plan_for_container_ships)）。**假设**

### 2.3 告警与标签
- 依据：高性能 HMI 的做法是灰度底，只给需要注意的东西上色（[控制工程网 2023](https://article.cechina.cn/23/0213/01/20230213012242.htm)），颜色越少越好（[控制工程网 2020](https://article.cechina.cn/20/1110/07/20201110073209.htm)）。
- 同一时间只有 1 条主告警享受"镜头飞过去 + 地面脉冲圆盘 + 一根细光柱"（地面圆盘借参考 8）。其余告警只在设备顶上留一个红点，进右侧列表排队。**假设**
- 标签分三级（**假设**）：
  - 全景：只显示泊位号和船名牌；
  - 中景：设备编号小牌 + 1 px 引线；
  - 近景：详情卡，带 FOLLOW / ORBIT（借参考 8）。
- 参考 4 那种满屏彩色图标加飞线，在 1080p 上告警会被淹没（截图观察）。

### 2.4 海面
- 屏上不得表示水深（[需求记录](/Users/zhangjiabin/Desktop/Company/screen-demo/docs/design/smart-port/01-requirements-qa.md)），所以海面不做深浅渐变，也不画等深线。
- 风格化水面通常有三样：岸边泡沫、按深度变色、噪声波纹（[Toon Water](https://roystan.net/articles/toon-water/)）。我们只取岸边泡沫和低频波纹，去掉按深度变色。**假设**
- 航道线照海图惯例用品红虚线（S-52 色标 CHMGD，[简书 S-52 颜色表](https://www.jianshu.com/p/6bde6efadbc4)）。进港船加 V 形尾迹。**假设**

| 适合观众 | 领导访客为主，调度也能读 | 调度 / 指挥中心（暗厅里久看） | 领导访客（有氛围）兼调度 |
| 最近的参考 | 参考 8 OPTICS；参考 9 洋山大屏的方块 | 参考 3 天津港夜间模式；参考 4 压暗底图 + 热度 | [参考 7 妈湾](https://www.51aes.com/cases/transport-hub/smart-port)；参考 3 天津港白天模式 |
| 风险 | 和 /hospital、/smart-ranch 同属亮色系；暗厅里白底刺眼，场地要压到约 #E6EAE8（假设）；品红和 /waiting 的紫色有点近 | 最容易撞 /energy（夜景 + 橙灯带）和 /building（金色夜景）：不能出现蓝紫天空和发光描边，琥珀要比 /building 的 #FFC65A 更偏橙；首页预览卡偏暗 | 中间调对比低，远看发灰；橙和告警红色相近，要靠形状和闪动区分；雾太重会像 /hometown 的傍晚 |

- 信号旗的红 / 黄 / 蓝 / 黑 / 白可以当方向 A 的状态色（[信号旗图表](https://en.wikipedia.org/wiki/International_maritime_signal_flags)）。**假设**
