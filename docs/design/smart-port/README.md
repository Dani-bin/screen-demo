## 选稿前要说明的出入

1. **岸桥颜色**：洋山四期实景的岸桥是红色（报道里是"一排排红色桥吊"）。三套设计稿都把岸桥画成浅色或银灰，把红色留给告警。选定后想改回红色，只改主题色，不影响布局。
2. **设备外形是简化模型**：岸桥、轨道吊、AGV、船都是按真实尺寸程序化搭的（轨距、起升高度、外伸距、船长、船宽）。选定后在实现阶段精修细节：拉杆、机房、爬梯、船上建筑、箱区端部的支架。
3. **数量与需求一致**：三维里岸桥 28、轨道吊 121、AGV 145、箱区 61、泊位 7，和需求、编号清单（`devices.json`）相同，没有冲突。
4. **时刻**：页面跟随真实时钟。选 B 的话，白天也会是夜景；选 A 或 C 的话，夜里还是白天。也可以组合，例如白天用 A / C、夜里用 B，按时刻切换，代价是要做两套皮肤。
5. **海图刻度只是装饰**：A 方向画面四周的刻度不标经纬度数值。

## 为什么没用 AI 生图

本项目可用的 Figma 生图只能按文字生成，不能拿白模底图做图生图。按文字生成的整景，岸桥、箱区的数量和排布不可能对上真实的洋山四期（28 台岸桥、61 个箱区），后面就没法对着它标定和还原。

所以中央三维沿用 `/smart-ranch` 的做法：直接用真实布局实时渲染。好处是"设计稿就是实现"，选定后的还原只差细节精修。AI 生图改为在选定方向后，为告警特写这类近景出 2–3 张概念图，作为岸桥、AGV 精修的参照（会消耗 Figma 积分）。
