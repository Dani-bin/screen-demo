# 05 需求方案

## 画布与适配

- 设计尺寸 1920×1080。现场屏按作品合集的惯例（单屏 1920×1080），用 rem 等比缩放（`postcss-pxtorem` + `amfe-flexible`）。没有现场主机信息，性能只在开发机上测。
- 路由 `/smart-port`；页面代码在 `src/views/smart-port/`：`scene/` 放三维（不依赖 Vue），`sim/` 放仿真器，`data/` 放布局。

## 首页模块

两条主线（船舶靠泊与装卸进度、自动化设备协同）左右分开，中间是三维码头。

| 区域 | 模块 | 展示内容 | 数据来源（测点 / 汇总） | 交互 |
|---|---|---|---|---|
| 顶部 | 标题 + 时钟 + 气象 | "洋山四期 · 智慧港口生产指挥"；北京时间；风速 / 阵风 / 风向、潮位 | `MET-01.*` | — |
| 顶部 | 关键指标条（5–6 个） | 今日吞吐量（TEU）、今日作业量（自然箱）、在泊船舶、平均船时效率、岸桥平均台时量（旁注纪录 63.88）、未结束告警 | `PORT.*` | 点告警数打开告警列表 |
| 左 | 在泊船舶 | 每船一行：船名 / 航次 / 船型 / 泊位；卸、装两段进度条（船形图标走在进度条上）；船时效率；计划 / 预计离泊；作业岸桥数；延误标红 | `<航次>.*`、`QCxx.vessel` | 点一行进入单船作业跟踪 |
| 左 | 靠离泊计划 | 未来 24 h：横轴时间、纵轴岸线位置（u）的甘特图，色块 = 航次，标出锚地待泊、靠泊中 | 仿真器 `schedule()` | 悬停看航次 |
| 左 | 今日吞吐 | 按小时的作业量柱状图 + 累计 TEU 折线 | 由 `PORT.movesToday` 逐小时差分 | — |
| 中央 | 三维码头 | 岸线、7 个泊位、61 个箱区、28 台岸桥、121 台轨道吊、145 台 AGV、换电站、船舶；周边海面、小洋山、一至三期、东海大桥作背景 | 全部设备状态 | 选中设备 / 船、悬停标签、拖拽接管镜头 |
| 右 | 设备运行状态 | 岸桥 / 轨道吊 / AGV 三组：作业、待机、故障、检修台数（环形或分段条） | `PORT.qc / rmg / agv.*` | 点某一类在三维里高亮 |
| 右 | 作业路协同 | 每条在作业的路一行：岸桥号、当前效率条、本船剩余关数、配车数、目标箱区；最慢的一路标出瓶颈原因（岸桥故障 / 轨道吊故障 / 阵风） | `QCxx.*`、`Yxx-S.state` | 点一行飞到那台岸桥 |
| 右 | AGV 与换电 | 电量分布（25% 换电线）；两座换电站：换电中、往返中、今日换电次数 | `AGVxxx.soc`、`BS-x.*` | — |
| 右 | 告警与事件 | 最新在前：级别、标题、对象、时刻、处置状态（待处置 / 处置中 / 已恢复）、处置班组 | `events` | 点一条飞到事发设备 |
| 底部 | 视图切换 + 图例 | 总览 / 船舶作业 / 设备协同 三个视角；状态色图例 | — | 切换镜头和图层 |

## 三维场景

- **必须出现的对象（编号）**：
  - 泊位 B01–B07；
  - 岸桥 QC01–QC28；
  - 箱区 Y01–Y61 与轨道吊（Y01-S，Y02-S / L … Y61-S / L，共 121 台）；
  - AGV001–AGV145；
  - 换电站 BS-1、BS-2；
  - 危险品 / 超限箱区 DG-01；
  - 生产指挥中心 CC-01，闸口 GATE-E / GATE-W；
  - 在泊和靠离泊中的船舶。

  数量与 `devices.json` 一致，缺一个就报错。
- **镜头**：
  - **主视角（总览）**：从海侧斜看整条岸线，船在前景，岸桥一字排开，箱区在后，东海大桥、小洋山作远景。具体机位在设计稿阶段定，标定后写进 `07-camera.json`。
  - **其它机位**：
    - 船舶作业：一条船 + 为它服务的岸桥和 AGV，约 600 m 宽；
    - 设备协同：岸桥后方的 AGV 带和海侧交换区；
    - 告警特写：单台设备，约 150 m 宽。
- **动效**：全部由仿真数据驱动，停机时不动。
  - 岸桥：大车沿轨道移到船位；主小车、门架小车往返；吊具升降（加速 1.5–2 倍）。
  - AGV：沿车道行驶（重载载箱、空驶空车），在岸桥下、箱区支架处停靠，去换电站。
  - 轨道吊：沿箱区移动。
  - 船舶：靠泊、离泊；甲板箱从船头到船尾按完成度变化。
  - 告警：主告警是地面脉冲圆盘 + 一根细光柱，其余告警是设备顶上的红点。
- **自动巡游**：总览 10 s → 依次看每条在泊作业船 8 s → 设备协同 8 s → 回总览。有新告警时打断 6 s，飞到事发设备。操作后暂停，30 s 无操作再恢复（同 /waiting）。
- **单船作业跟踪**：点船（或左侧列表）进入。
  - 镜头跟这条船。
  - 左侧换成这条船的详情：卸 / 装进度、逐贝完成情况（行箱位剖面）、为它服务的岸桥台时量、配车数、预计离泊。
  - 三维里只高亮这条船、它的岸桥和 AGV 路径光带，其余压暗。
  - 右上角"退出跟踪"按钮。
- **标签分级**：
  - 全景：泊位号 + 船名牌；
  - 中景：设备编号小牌 + 1 px 引线；
  - 近景：详情卡。

## 状态

| 状态 | 呈现 |
|---|---|
| 正常 | 设备按状态着色：作业 = 主色，待机 = 中性灰，检修 = 斜纹灰。箱子 4 种中性色，强调色只给被跟踪船的箱子 |
| 告警 | 主告警：镜头飞过去 + 地面脉冲圆盘 + 细光柱 + 告警卡；其余告警：设备顶上红点 + 右侧列表。岸桥故障时该路的 AGV 停在岸桥下排队 |
| 数据过期 | AGV 定位中断：车体变灰、停在最后已知位置，旁边标"定位中断 xx s"；面板里该车的数值置灰并标"过期" |
| 质量不确定 | 风速仪读数异常：数值后加"?"并用虚线框；不参与预警判断 |
| 延误 | 在泊船舶行标红并显示"预计晚 xx 分钟"；甘特图色块尾部画出延误段 |
| 巡游 / 手动 | 右上角显示"自动巡游中"或"手动 · 30 s 后恢复" |

不做时间轴回放（需求已定）。快照的 1 小时只用于设计稿和验收比对，比对时用 `--state` 固定到同一时刻。
