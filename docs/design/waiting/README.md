# 候诊大厅大屏 demo · 设计稿

现在医院候诊区的大屏多是 LED 条屏，只能显示某科室候诊多少人、具体是谁、哪些是复诊。
本 demo 用 3D 可视化展示**每间诊室**的候诊状态：待诊 / 复诊 / 过诊各多少人、都是谁；自动轮播各诊室的就诊情况（含当前就诊时长）；常驻显示当前叫号，并在三维里高亮对应诊室。
数据全部模拟，医院是虚构的（与 `/hospital` 院内导航是同一家医院、同一栋楼）。

流程：拷问需求（2026-10-17，第一轮 14 题全部按推荐）→ **设计稿（本目录，待确认）** → 实现页面。

## 已确认的设定（2026-10-17）

| 项 | 结论 |
|---|---|
| 定位 | 作品集 demo，虚构医院，数据全模拟；模拟器与页面之间留一层干净的数据接口，以后可换成 HIS / 叫号系统 |
| 页面 | 独立路由（暂定 `/waiting`），与 `/hospital` 互不依赖，但用同一家医院的名字和世界观 |
| 范围 | `/hospital` 2F 的内科组：南排 8 间诊室 213–220（心内 ×2、呼吸 ×2、消化 ×2、神经内科、内分泌），隔着走廊正对内科候诊区 |
| 状态 | **待诊**：已签到、按序排队；**复诊**：做完检查拿结果回来找同一位医生，不重新排队，优先插叫；**过诊**：连呼 2 次未到，进过号名单，重新签到后排到当前位置后第 3 位；另计**已诊**人数（只显示数字） |
| 当前就诊 | 显示开始时刻 + 已就诊时长（走秒），超过 15 分钟提醒；医生信息里显示出诊时段 |
| 姓名 | 号码 + 脱敏姓名：`A102 潘*涛`，两个字的名字显示 `郑*` |
| 叫号 | 叫号条常驻显示最近一次叫号，同一号连呼 2 次；三维里被叫诊室橙色高亮（室内地面变暖橙、门前光环、标签变橙并写"叫号中"）；镜头打断轮播飞到该诊室约 6 秒；最近叫号保留 6 条 |
| 语音 | 提示音 + 浏览器中文语音念叫号词；浏览器限制自动出声，默认静音，右上角一键开启 |
| 轮播 | 每间诊室停 8 秒（镜头推近，右栏换成该诊室详情）；8 间转完回全景 10 秒；叫号插播；点诊室可锁定，30 秒无操作恢复 |
| 模拟 | 固定随机种子，显示真实时钟，任何时候打开都是"门诊进行中"；计时不压缩，每人就诊 1.5–4 分钟，全区约 15 秒叫一次号；约 10% 叫号未到转过号；复诊陆续回来 |
| 屏幕 | 横屏 16:9，设计稿 1920 × 1080 |
| 风格 | 浅色，沿用 `/hospital` 设计稿 v1（白墙浅灰地面、导视牌深绿 `#0F5B4C`、项目三套字体） |
| 三维里的人 | 每间诊室上方一块状态标签；诊室里有医生和正在就诊的患者小人；候诊区座椅上有抽象小人（只表现人气，不和名单一一对应） |
| 名单位置 | 三维标签只放房间号 + 三个人数；完整名单在右栏（轮播到哪间显示哪间，每组最多 8 人，再多写"等 N 人"）；左下常驻过号名单 |

## 我（Claude）补定的细节 —— 请看图时一并核对

- **复诊插队规则**：每叫 2 位待诊，插叫 1 位复诊（写在诊室一览的脚注里）。
- **号码**：分诊台签到时全区统一发号（A001 起），所以同一诊室的号码不连续；复诊保留原号码。
- **颜色语义**：橙色只表示"叫号"。蓝 = 待诊，紫 = 复诊，玫红 = 过诊，绿点 = 就诊中，深绿 = 导视牌。
  第一轮说的"超过 15 分钟变橙色"改成了**暗琥珀色**（`#B7791F`），免得和叫号的橙色混淆。
- **轮播中的诊室**：标签变成深绿的大标签（多显示"就诊中 06:28"和带文字的三个人数），三维里描一圈深绿框；左栏对应行加深绿竖条。
- **左栏**：候诊概况（四个总数 + 平均等候 / 就诊时长）→ 诊室一览（8 行：房间号、科室、医生、当前号码与时长、三个人数）→ 过号名单。
- **右栏**：轮播进度（8 个点，"6 / 8 · 5 秒后切换"，叫号时显示"叫号插播"）→ 诊室牌 → 当前就诊（或"叫号中 · 等待入室"）→ 待诊 / 复诊 / 过诊三组名单。
- **中下**：最近叫号 6 张卡片，状态写成文字（呼叫中 / 已入室 / 复诊 · 已入室 / 未到 · 过号），不只靠颜色区分。

## AI 三维图和 CAD（`/hospital` 2F）对不上的地方 —— 确认前请定规则

- **诊室比例**：AI 图每间诊室接近方形，CAD 是 3.6 × 7.2 m（进深是开间的 2 倍）。
- **候诊座椅**：AI 图是 3 排 × 3 组，CAD 是 5 排 × 2 组（中间一条南北向通道）。
- **分诊台**：AI 图在候诊区正前方居中，后面跟一排椅子；CAD 的内科分诊台在西北角（x 13–17 m），二次候诊座椅在分诊台北侧，离诊室较远。
- **两端**：AI 图右端是一间办公室 + 一间处置室，左端是小块候诊区；CAD 是西南角内科处置室、东侧南侧候诊区（大体一致）。
- **一致的部分**：一排 8 间诊室、剖到半高的墙、门朝候诊区、诊室里医生 + 患者 + 检查床、走廊对面成排座椅、浅色写实风格。
- 建议规则（与 `/hospital` 相同）：**三维图定风格，布局以 CAD 为准**。两个页面是同一栋楼，按 CAD 建模，平面只维护一份 `plan.py`。

## 选定 E 风格并实现（2026-10-17）

- 用户选了 **E 缤纷等距插画**。补出轮播推近画面 `15-style-e-candy-tour.png`（推近 218，216 仍在第 2 次呼叫），命令是 `python3 scripts/waiting/draft_v2.py tour e`。
- 页面路由 `/waiting`，代码在 `src/views/waiting/`。首页已登记，预览图 `public/home/waiting.webp` 是真实页面截图。
- **平面**：`scripts/waiting/build_plan.py` 从 `/hospital` 的 `scripts/hospital/plan.py` 截出 2F 内科组，生成 `data/plan.json`，诊室、墙、窗、座椅、家具都以 CAD 为准。
  截取范围多带了西侧的处置室、医生办公室、西楼梯、卫生间，东侧一角南侧候诊区，以及中庭上空的一块（楼板挖洞、围玻璃栏杆，洞底露出 1F 地面）。
- **三维**：`scene/WaitingScene.js` 程序化建模，`scene/theme.js` 管配色和尺寸。
  - 诊室：前墙和隔墙剖到 1.4 m，外墙 2.6 m 带窗。
  - 状态柱：每人高 0.24 m，叫号时诊室门会打开。
  - 小人：大头卡通，放大 1.4 倍；候诊区坐着的人数等于当前待诊 + 复诊人数。
- **模拟**：`sim/simulator.js` 加 `data/rooms.js`。3 小时校验结果：约 22 秒叫一次号，过号率约 9%，各诊室待诊人数保持在 2–12 人。
- **轮播**（`index.vue`）：
  - 开屏先停全景 4 秒，之后逐间诊室各 8 秒，转完回全景 10 秒，依次循环。
  - 新叫号（第 1 次呼叫）插播 6 秒，结束后接着原来的顺序往下轮。
  - 点击锁定某间诊室，30 秒无操作后恢复轮播。
  - 推近时（轮播、插播、锁定都算）三维区域右上角有一个"看全景"按钮，锁定时显示为"解除锁定 · 看全景"。
    点了拉回全景并停住，这期间新叫号不会打断，被叫诊室照样亮橙色；30 秒无操作后从第一间诊室重新轮播。（用户 2026-10-17 提出）
- **和设计稿不同的地方**：
  - 图例改成竖排，只在全景时显示（推近时会挡住标签）。
  - 全景里诊室在画面中显得小一些，因为状态柱和标签上方要留出空间。
  - 候诊区的小人按实际人数摆，所以比设计稿密。

## 人物换成 Blender 建模（2026-10-17）

- **脚本**：`scripts/blender/waiting/`（`toy.py` 几何工具、`people.py` 人物定义、`build.py` 构建 / 预览 / 导出）。
  共 9 个人物：男医生（眼镜、听诊器、领带）、女医生（病历夹）、护士（护士帽、胸牌），以及老人（卷发、拐杖）、长发女生（手机）、戴口罩大叔、耳机少年、波波头阿姨、奶奶。

  五官是贴在头上的扁椭球：大眼加两颗高光、睫毛、腮红、小鼻子；嘴是一串贴脸的扁椭球，换掉细管是因为细管会反出一道白光。
