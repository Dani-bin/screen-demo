## 园区级：从设计稿到实时三维的还原做法

充电站 demo 的教训是「AI 设计稿 → 脚本建模 → 实时渲染」每一步都在丢东西（几何靠意会、光照留在离线渲染里、取景尺度不对、没有逐步对照）。园区级对应的做法：

1. **几何用真实数据**：楼体轮廓 / 层数 / 斜屋顶、道路、草地、水面全部来自 OSM（`scripts/build-park-layout.mjs`），不按 AI 图去猜。
2. **光照烘焙进地面**：Cycles 把路灯光斑、楼体溢光、树影烘进 `park_ground.webp`，实时端直接显示；楼体靠窗灯贴图 + 夜空环境反射 + 辉光。
3. **远看尺度下做贴图**：一扇窗在画面上不到两个像素，窗灯按「层」分全暗 / 微亮 / 正常 / 通明四档成片亮，再撒零星亮窗，而不是逐窗随机；只有通明档超过辉光阈值。
4. **光影靠对比**：烘焙时压低环境光与月光、加强路灯并给园内步道加地灯，地面形成明暗光池；辉光只给真正的光源，沙盘描边与车道线不泛光；
   树冠用 4～7 个带起伏的叶团簇成，顶点色里写入上亮下暗的体积，靠近路灯 / 地灯的树按距离染暖色；楼体墙根叠一层暖色泛光。
5. **竖向造型按实景照片补**：OSM 只有平面轮廓，楼的外廓、顶部、边框与表皮按设计稿 + 实景照片还原（`scripts/blender/park/buildings.py`、`palette.py`）：
   - 双子塔：塔身向上收分成「口红」形（顶部约为底部 0.86），斜切口外沿倒成圆肩，冠顶内凹、凹面里两圈同心光环；
     外表皮为深蓝玻璃外罩白色「冰裂纹」铝格栅（格栅带微弱冷白自发光，窗灯从格栅缝里透出）；大堂玻璃有竖梃横档；
     金色描边只沿冠顶外沿、大堂顶和默认视角下塔身左右轮廓。
   - 鹅卵石楼：轮廓尖角倒圆，外墙到顶按四分之一椭圆向内卷成圆弧檐口，檐口上段为银白金属（实景的蛋形立面 + 设计稿的白色厚檐口）；
     外表皮为白色层间带 + 斜向枝杈格构；屋面浅灰、中部一块屋顶花园。
   - 会议中心：银灰金属壳带经向肋条与环梁，顶部深色椭圆天窗，檐口一圈银边。
   - 外墙用共用顶点的放样网格做平滑着色，消除逐段墙面的折纸感。
   - 场地（第四轮，按设计稿）：树改为成簇种植（树团之间留出草坪，行道树 14 m 一棵，总数约 1000 棵），树冠比真实放大一档；
     园区地块整体铺草坪、楼前一圈铺装广场；道路按等级加宽一档；在园区空地按「最大空圆」生成 5 处景观湖与环湖步道（示意，OSM 没有）；
     行驶道路两侧交错立路灯，每片水面一圈庭院灯；实时端在烘焙水面上叠一层带菲涅尔反射、亮岸边与随机波光的水面（`scene/park/water.js`）。
   - 道路（第五轮）：沥青由近黑改为中灰、人行道浅灰、加浅色路缘石，园区铺装提亮一档，夜景里路面和草地拉开明度；
     标线按路幅分车道（白虚线），路缘内白实线，路口（行驶道路端点落在另一条路上且夹角大于 35°）画斑马线；标线带少量自发光。
   - 草坪（第六轮）：草地贴图按 sRGB 存，原来画到 0.03～0.08，换成线性反照率不到 0.01，夜景烘焙后整片发黑；
     改为白天草坪的中绿（sRGB 约 0.14 / 0.34 / 0.12），烘焙后草坪在夜里仍是中绿、灯下有暖色光斑。夜景地面材质要按「和相邻地物拉开明度」来定。
   - 草坪再调暖调亮（sRGB 约 0.22 / 0.46 / 0.12 的黄绿）；园内服务道路与步道改为米灰色园路（原来用沥青，在草坪里发黑）。
     园路发黑的另一个原因是烘焙：Lightmap 是平面投影，上下重叠的地面层共用同一块像素、后烘的覆盖先烘的，
     被上层遮住的下层烘出来是黑的。所以 `site.ground` 里各层严格按从下到上生成，路带先生成全部接头再生成路段，
     同层的多条路逐条抬高 0.4 mm（`Z_STEP`），交叉处不同高。
   - 湖面光影：实时水面 shader 里按镜面反射算出每盏岸边灯 / 路灯 / 塔楼在水里的倒影位置，沿视线拉成光带、被波纹切成段并随时间晃动，
     灯下近岸水面一圈柔光，底色叠两层流动的波纹明暗（`scene/park/water.js`，光源由 `ParkScene._waterLights` 从灯具实例收集，每片水面取最近 16 个）。
     水体按设计稿改为被灯照亮的天蓝色（不是黑水），叠两层水底焦散光纹；灯照亮水体的量按指数封顶（岸边灯多，直接累加会整片发白）。
6. **固定相机逐张对照**：Blender 预览与 three.js 同一方位角 / 俯角（东南偏东 -25°、俯角 35°），每轮改动都截图与设计稿对比（`21-park-compare.png`）。

与设计稿仍有的差异：真实园区约 500 × 810 m，比 AI 图里的园区大得多，默认取景下单辆车、单盏灯只有几个像素（可滚轮拉近）；
鹅卵石楼的数量与位置以 OSM 为准，与 AI 图不同；景观湖、加宽的路幅是为贴近设计稿加的，不是真实数据。

## 楼宇级：实现做法

设计稿是「X 光」全息示意图，不追求写实，所以没有走 Blender，全部在 three.js 里程序化生成（`src/views/building/scene/tower/`）：

- **几何来自真实数据**：塔楼椭圆平面、斜切屋顶方向与高差取自 OSM（`scripts/build-park-layout.mjs` 导出 `PARK_TOWERS`），收分与园区级模型一致。
- **竖向按示意比例**：真实细高比约 4.2，按真实比例放进画面像一根针；标准层层高按 2.2 m 示意（真实 3.76 m）、地下层按 13 m，接近设计稿的比例。
- **外壳 / 楼板 / 核心筒都是加法混合的着色器**：外壳按楼层数据贴图（入驻率、告警、设备层、在岗密度）亮窗；核心筒井道里电梯光点往返；选中楼层外壳挖空、金色抽屉向画面右侧抽出（按 2.6 倍层高显示，看得清室内工位）。
- **地下剖切**：基座沿正对相机的竖直平面切开（剖面模型），露出 B1 车库、B2 冷水机组与配电柜（告警柜红色波纹）、B3 水泵与水箱。
- **相机朝向自动计算**：让屋顶下坡方向朝画面右侧（设计稿左高右低），南北塔都适用。
- **四个视图**：楼层剖切 / 透视外立面 / 机电系统（立管流动 + 设备层绿色）/ 人员热力（楼板按在岗密度着色），切换时各项亮度插值过渡。

按概念图 02 返工（2026-10-08）：底座改为直径约塔身 2.25 倍的石材圆台（砌块贴图 + 微弱自发光），正面挖方形剖口一直切到广场，
三层机房按 13 m 示意层高展开（设备同比放大：车库 + 新风机组、冷水机组 + 管道 + 一排绿灯配电柜、水泵 + 水箱），灯盘压在辉光阈值以下；
裙楼加高加宽、广场一圈树；标准层 2.2 m 让塔身高宽比接近 2.7；每层玻璃里摆亮灯工位（按入驻率，InstancedMesh，抽出层隐藏）；
核心筒收窄成一道光柱；玻璃描边改成偏蓝，辉光强度降到 0.35，避免几十层叠加后整栋发白。

与设计稿仍有的差异：塔楼平面保持 OSM 真实椭圆比例；地下剖口是平直的一刀（概念图剖口轮廓略不规则）；裙楼没做两级台阶。

### 写实化（2026-10-08，第三版）

用户反馈「模型没有设计稿那种写实质感」，塔楼从发光着色器改为真实构件（`scene/tower/floorKit.js`）：
每层生成两块合并网格——实体（楼板、家具，顶点色 + 少量自发光模拟室内灯照亮）与发光件（吊顶灯盘、楼板外沿冷光线、竖梃、桌面屏幕）；
整栋一张 `MeshPhysicalMaterial` 蓝玻璃（只画外侧面，避免背面叠加成白雾），shader 注入抽屉挖空、悬浮青色、告警红色呼吸与轮廓菲涅尔；
核心筒光柱关闭深度测试透出整栋楼；人员热力在楼板上叠一层按在岗密度着色的光面；地下与底座沿用第二版。
调参要点：室内整体要暗，亮的只有灯盘、层线与屏幕；58 层在画面里每层不到 10 像素，层线隔层一条亮、竖梃 6 m 一根，否则糊成灰网。

### Blender 建模 + 烘焙室内灯光（2026-10-09，第四版）

实时渲染算不出几十层室内的灯光照射与软阴影，楼层室内改为 Blender 建模、Cycles 烘焙（`scripts/blender/tower/`，做法同园区级）：
- 每座塔 9 种楼层变体：办公 5 种（亮灯比例 100 / 85 / 70 / 55 / 40%，12 个分区按比例点亮）、大堂、商业、设备层、空中会所；
  三维里按楼层数据（类型、入驻率）给每层挑变体，相邻楼层避免重复，按该层收分缩放，斜屋顶下几层用裁剪平面切掉伸出部分。
- 每个变体两部分：楼板顶面 + 核心筒墙烘到 2048² 贴图（大面、明暗细节多）；家具、灯盘、天花、板边烘到面角顶点色
  （家具上千个小面，放进贴图会切成上万个 UV 岛，缝隙把贴图挤满）。灯盘是自发光网格，在 Cycles 里真实照亮桌椅与地面，夜空从四周照进熄灯区。
- 顶点色烘出来是 HDR（灯盘十几），导出时按最大通道压到 1，避免整片泛光；GLB 用 meshopt 压缩、不导出法线（显示用 MeshBasicMaterial）。
- 玻璃幕墙、层线、竖梃、核心筒光柱、底座与地下剖口仍是 three.js（需要实时反射 / 动画）。抽出的楼层放大 1.15 倍，水平裁掉天花与灯盘露出室内。

### 地下机房烘焙、屋顶层、远景窗灯（2026-10-09，第五版）

- 地下 B1～B3 机房也改为 Blender 建模烘焙（`scripts/blender/tower/basement.py`）：楼板 / 墙 / 剖面墙烘贴图，车辆、冷水机组、配电柜、水泵、水箱、管道、
  灯管烘顶点色；告警配电柜是红色自发光，烘焙时把周围照成红色，three.js 只保留剖口描边、拾取体与红色波纹动画。机房层高 13 m，灯管强度 45，采样加倍压噪点。
- 斜屋顶下的楼层单独建模（`top_<层号>`），楼板与家具按屋面裁剪，不再出现被屋面切开的家具。
- 远景读不出室内：塔身玻璃按每层亮灯比例在窗格里透出暖光，随相机距离渐变（近看玻璃通透、显示烘焙的室内；远看读成设计稿那种一格格亮窗）。
