# 演示中心首页 设计文档

日期：2026-10-06
状态：已确认，待实现

## 背景与目标

项目定位为大屏 demo 合集，目前有 `/school`（智慧校园三维导览）与 `/city`（城市三维总览）两个演示，
但没有统一入口：根路径直接重定向到 `/school`。

新增一个首页，集中展示每个演示的介绍与预览图，点击即进入对应演示；以后新增演示只改一份数据文件。

## 关键决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 版式 | 聚焦轮播：左侧介绍 + 右侧大预览 + 底部演示列表 | 用户在「明亮画廊 / 深色展厅 / 聚焦轮播」三版效果图中选定 |
| 调性 | 暖白底 `#f4f1ea` + 当前演示主题色 | 与两个演示的明亮风格一致，跳转时不反差 |
| 预览图 | 演示页真实截图，静态 webp | 首页不跑三维场景，打开快、不抢 GPU；截图脚本可一键重拍 |
| 自动轮播 | 每 8 秒切到下一个演示，鼠标悬停时暂停 | 大屏多数时间无人值守 |
| 路由 | 新增 `/home`，根路径重定向改指 `/home`，加入 `PUBLIC_PATHS` | 首页是总入口，免登录、不加载百度地图 |
| 数据 | `src/views/home/data/demos.js` 静态列表 | 新增演示只改这一个文件 |
| 演示页 | 不改动 | 范围控制；返回首页走浏览器后退 |

- 顶栏：左侧品牌标记 + 标题「三维可视化大屏 · 演示中心」+ `SHOWCASE`，右侧时钟（时分秒 + 日期 + 星期，每秒刷新）
- 左栏（宽 560）：序号 `02 / 02`、大标题（阿里妈妈数黑体 72px）、英文名、副标题、介绍、标签、3 个关键指标、「进入演示」按钮
- 右侧大预览（宽 1080，16:9，白色 10px 外框 + 投影），点击同样进入演示
- 右侧斜切背景色块：当前演示主题色与底色 12% 混合，切换时颜色过渡
- 底部演示列表：每项为缩略图 + 序号 + 名称 + 副标题；当前项白底高亮，底边进度条显示距下次轮播的剩余时间
- 垂直方向用 flex 分配（顶栏 / 主区 / 列表），非 16:9 屏幕也不会重叠

字体沿用项目已注册的字体：标题「Alimama ShuHeiTi」，数字「DIN」，正文「Source Han Sans CN」。

## 交互

| 操作 | 行为 |
|---|---|
| 无操作 | 每 8 秒切到下一个演示，末尾回到第一个；只有 1 个演示时不轮播 |
| 鼠标悬停在左栏 / 大预览 / 列表上 | 暂停轮播（进度条停住），移开后从停住处继续 |
| 点击列表项 | 切到该演示，进度条从头开始 |
| 点击「进入演示」或大预览 | `router.push(demo.path)` 进入演示 |
| 键盘 ← / → | 切换上一个 / 下一个 |
| 键盘 Enter | 进入当前演示 |

轮播计时由进度条的 CSS 动画驱动：动画结束（`animationend`）即切到下一个，暂停即 `animation-play-state: paused`。
计时与进度显示只有一个来源，不会出现进度条与实际切换不同步。

切换动效：左栏内容淡出淡入并轻微上移（Vue `<Transition mode="out-in">`），大预览两张图交叉淡入淡出，
背景色块颜色过渡；`prefers-reduced-motion` 下取消位移、缩短时长。

## 数据结构

`src/views/home/data/demos.js` 导出 `DEMOS` 数组，每项：

| 字段 | 说明 |
|---|---|
| `key` | 唯一标识，如 `school` |
| `path` | 演示路由，如 `/school` |
| `name` / `en` | 中文名 / 英文名 |
| `subTitle` | 副标题（演示对象） |
| `desc` | 介绍，两三行 |
| `tags` | 3 个以内的特性标签 |
| `stats` | 3 个关键指标 `{ value, unit, key }` |
| `accent` | 主题色（按钮、序号、进度条、背景色块） |
| `preview` | 预览图，相对 `public/` 的路径，由页面拼上 `BASE_URL`（生产环境部署在 `/bi/` 下） |

两条初始数据：

- 智慧校园三维导览（`/school`，主题色砖红 `#a8432e`）：6 站导览地标、30 亩、148 × 130 m 场景尺度
- 城市三维总览（`/city`，主题色青绿 `#2f8f96`）：12 站城市地标、18,750 栋真实建筑、8.8 × 7.5 km 街区范围
  （建筑数取 `chengdu.json` 的 `meta.mainCounts.buildings`，范围取 `meta.clip` 的东西 / 南北跨度）

## 预览图

- 存放：`public/home/<key>.webp`，1920 × 1080
- 生成：`node scripts/capture-home-previews.mjs [devServerUrl]`。用本机 Chrome 无头模式 + 调试协议，
  依次打开每个演示，等场景稳定后截图存为 webp；演示列表从 `demos.js` 读取，新增演示后重跑即可
  - Chrome 路径默认 macOS 安装位置，可用 `CHROME_PATH` 覆盖
  - 每个演示的等待时长可在脚本里按 key 配置（城市场景加载较慢）
- 页面加载时预加载全部预览图，切换时不闪白

## 文件结构

```
src/views/home/
  index.vue                 页面外壳：布局、当前索引、轮播与键盘逻辑
  data/demos.js             演示列表（唯一需要随新演示修改的文件）
  components/HomeHead.vue   顶栏：品牌 + 时钟
  components/DemoDetail.vue 左栏：当前演示介绍与「进入演示」
  components/DemoStage.vue  右侧大预览（交叉淡入淡出）
  components/DemoRail.vue   底部演示列表 + 进度条（发出 select / finish 事件）
public/home/*.webp          预览图
scripts/capture-home-previews.mjs  预览图截图脚本
```

改动的既有文件：`src/router/index.js`（新增 `/home`、根路径重定向）、`src/permission.js`（`PUBLIC_PATHS` 加 `/home`）、
`CLAUDE.md`（路由说明与截图脚本命令）。

## 异常与边界

- 预览图缺失：图位显示主题色淡色占位块与演示名，不显示破图
- 演示数为 1：不启动轮播、不显示进度条
- 离开首页：卸载时移除键盘监听；轮播靠 CSS 动画驱动，无定时器需要清理（时钟定时器在 `HomeHead` 卸载时清理）

## 验证

项目无测试框架，按以下方式验证：

1. 截图脚本生成两张预览图，人工确认画面
2. 预览服务器打开 `/#/` 应落在首页；无头 Chrome 截首页 1920 × 1080 与效果图 C 对照
3. 等待 8 秒确认自动切换；模拟悬停确认暂停；点击列表项、按键 ← → Enter、点击「进入演示」确认跳转到 `/school`、`/city`
4. `npx eslint --max-warnings 0 "src/views/home/**/*.{vue,js}"` 通过
5. `yarn build` 通过，产物中预览图路径带 `/bi/` 前缀
