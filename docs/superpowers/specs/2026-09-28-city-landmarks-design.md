# 城市三维总览 · 景点精细建模 设计文档

日期：2026-09-28
状态：已确认（用户授权按推荐方案直接实施）
前置：`2026-09-28-city-3d-design.md`（城市三维总览第一版，已实现）

## 背景与目标

第一版的 7 个景点只是 OSM 轮廓挤出的方盒子加一个落点球，辨识度不够。
本期把每个景点按真实建筑形制做成「微缩插画风」的精细模型：
屋顶形式、层数、朝向、配色、标志性细节都以实景资料为依据，
风格参照用户给的微缩城市插画（饱和配色、翘角屋檐、红柱金顶、圆润可爱）。

## 关键决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 建模方式 | three.js 代码程序化建模 | 用户选定；零外部素材，与现有城市风格统一 |
| 保真度 | 「可辨认的微缩模型」级 | 形制、比例、朝向、配色、标志细节真实；不做斗拱雕花等微观细节 |
| 位置与朝向 | 以 OSM 实测为准 | 老城网格偏北向东 30°～38°；按名称从几何数据里取真实轮廓 |
| 与城市的衔接 | 景点范围内隐藏通用方盒楼，换成精细模型 | 避免重叠；其余城区不变 |
| 历史街区 | 宽窄巷子、太古里、大慈寺周边的低层 OSM 建筑改为坡屋顶民居 | 这两处的辨识度来自成片灰瓦坡屋顶，而不是某一栋楼 |
| 合批 | 每个景点烘焙成一个顶点色 Mesh（熊猫等少数件另算） | 7 个景点新增 draw call 控制在 10 个左右 |
| 景点坐标 | 按 OSM 纠正 | 原坐标宽窄巷子偏约 500 m、合江亭偏约 800 m、文殊院约 350 m、天府广场约 300 m |

## 架构

```
src/views/city/scene/landmarks/
├── kit/
│   ├── builder.js     顶点色合批器：add(geometry, color, matrix?) → bake() 出单个几何体
│   ├── footprint.js   轮廓工具：按名称查楼、中心、最小外接矩形（中心/长宽/朝向角）、点是否在区域内
│   ├── roofs.js       屋顶：双坡悬山、歇山（翘角）、n 边攒尖、重檐组合、正脊与宝顶
│   ├── parts.js       构件：台基与台阶、柱列、栏杆、墙体（带门窗色带）、灯笼、拱券、塔刹
│   └── figures.js     小件：低多边形熊猫、游船、金色圆盘、图腾柱
├── tianfu.js          天府广场
├── taikooli.js        太古里 · 大慈寺
├── ifs.js             成都 IFS + 熊猫
├── kuanzhai.js        宽窄巷子
├── peoplesPark.js     人民公园 · 纪念碑 · 鹤鸣茶社
├── wenshu.js          文殊院 + 千佛和平塔
├── hejiang.js         合江亭 + 安顺廊桥
└── index.js           注册表：createLandmarks(ctx) 汇总各景点
```

### 景点模块接口

每个景点模块导出 `build(ctx)`，返回：

```js
{
  meshes: [Mesh],          // 通常 1 个顶点色合批 Mesh，熊猫等可单独一个
  zones: [[[x, z], ...]],  // 替换区：区域内的通用方盒楼被隐藏
  markerHeight: number,    // 落点球底座高度（替代 markerBaseHeight 的估算）
  update?(t)               // 可选动画（游船漂动、喷泉起伏）
}
```

`ctx` 提供：`project`（经纬度 → 局部坐标）、`buildings`（几何数据）、`footprint`（kit 工具）、
`theme`、`spot`（该景点的数据与局部坐标）。

### 注册表与接入

- `createLandmarks({ geometry, spots, theme, project })` 依次调用 7 个模块，汇总：
  `group`、`excluded`（被隐藏的建筑索引 Set）、`markerHeights`、`pickables`（Mesh → 景点索引）、`update(t)`、`dispose()`。
- `buildings.js` 的 `createBuildings(buildings, theme, excluded)` 跳过被排除的楼；
  `faceToBuilding` 仍记录原始索引。
- `CityScene` 先建景点（拿到 `excluded`），再建通用楼；落点球高度改用 `markerHeights`。
- 点击景点模型：飞往该景点（`tour.gotoStop(i, true)`），不弹楼体气泡。
- 单个景点模块抛异常时跳过该景点并 `console.error`，城市照常显示（不连带整场景失败）。

### 历史街区坡屋顶

`kit` 提供 `pitchedHouse(builder, footprint, opts)`：取 OSM 轮廓的最小外接矩形，
墙体按轮廓挤出到檐口高度，上面盖一个沿长边的双坡屋顶（出檐 0.6 m，灰瓦色）。
- 宽窄巷子区域：檐口 4～6 m、屋脊 +2.5 m，青砖灰墙与白灰墙随机，临巷挂红灯笼。
- 太古里区域：檐口 8～12 m、屋脊 +3 m，深木格栅色墙体 + 通高玻璃色带，屋顶深灰。

### 深链接

`#/city?spot=N` 让巡览从第 N 站开始（0 起）。既方便分享某个景点的大屏画面，也用于逐个景点截图验收。

| 金黄琉璃 / 宝顶 | #E8B838 |
| 红柱 / 红木 | #B8352B |
| 赭黄院墙 | #D9A640 |
| 汉白玉 / 浅石 | #EFEAE0 |
| 台基花岗岩 | #B9B6AE |
| 青砖 | #6B7076 |
| 白灰墙 | #EDE6D6 |
| 深木格栅 | #5A4A3C |
| 铸铁 | #3A3C40 |
| 塔身暗红 | #8A2E26 |
| 熊猫黑 / 白 | #1E1E22 / #F4F4F0 |

造型规则：
- 屋檐四角上翘（歇山、攒尖都做），翘起高度约出檐的 35%。
- 屋脊加一道细脊，攒尖顶加宝顶。
- 柱子统一红色、柱径约 0.35 m（按实际尺寸缩放）。
- 所有古建坐在浅色台基上。
- 除熊猫外不用 flatShading，保持圆润感。

## 各景点规格

依据详见文末「资料来源」。尺寸为米，朝向为长轴相对正北的顺时针角。

### 1. 天府广场（正南北）
- 广场地面：OSM 广场面铺浅灰石材；中心金色太阳神鸟圆盘 Φ54；S 形分界线把东西两半分开。
- 12 根文化图腾柱：高 12、Φ1.2，深绿柱身 + 顶部金球，沿广场周边均布。
- 毛主席像：北侧，面朝正南。三级台基共 8.1 m + 红褐基座 7.1 m + 白色像身 12.3 m（简化为立像轮廓）。
- 四川科技馆：替换 OSM 轮廓，142 × 109 × 30，米黄墙、砖红线脚与转角塔楼、中部深色玻璃柱廊。
- 成都博物馆：替换 OSM 轮廓，高 46.9，金色铜网立面 + 绿色玻璃入口。
- 四川省图书馆：替换 OSM 轮廓，高 38.5，两座阙楼夹台阶式中庭，竖向石材纹。
- 两道条形喷泉 76 × 8（浅蓝水面 + 白色水柱，轻微起伏动画）。

### 2. 春熙路·太古里 · 大慈寺（网格约 30°）
- 太古里区域低层楼改为深灰坡屋顶店铺（见「历史街区坡屋顶」）。
- 大慈寺：按 OSM 名称取弥勒殿、观音殿、药师殿等轮廓，建单檐歇山殿堂，红墙、深灰瓦、石台基；寺院外围一圈红墙。
- 字库塔：六角两层、高 7.6、青砖色。

### 3. 成都 IFS（网格约 30°）
- 塔楼：T1、T2 高 248，T3 高 188，T4 高 198，按 OSM 轮廓做蓝色玻璃盒子，顶部略收。
- 裙楼：按 OSM 轮廓，高 40，米色石材横纹 + 若干凸出玻璃盒；屋顶绿化花园（草地、小树）。
- 熊猫「I Am Here」：高 15，低多边形（flatShading），趴在面向红星路一侧的裙楼女儿墙上，
  头和前爪探进屋顶花园，后腿悬空垂在立面外。这是本景点的主角。

### 4. 宽窄巷子（东西向）
- 三条平行巷：宽巷子宽 7.7、窄巷子宽 4.5、井巷子宽 5，按 OSM 巷道中线铺石板路面。
- 区域内低层楼改为川西民居：灰瓦悬山、青砖/白灰墙、院落天井种树、临巷红灯笼。
- 井巷子南侧 400 m 砖砌文化墙（高 3、青砖色）。
- 东入口门楼（宽窄巷子东广场处）：单檐悬山牌坊，红柱灰瓦。

### 5. 人民公园 · 辛亥秋保路死事纪念碑
- 纪念碑：总高 31.86。圆形碑台 Φ17 × 4.2 + 石栏 + 四向台阶；四层收分碑座；方形碑身 15 × 2 × 2（中部内凹刻字面白色）；
  四角攒尖琉璃顶约 6，顶四角各一座小塔。
- 鹤鸣茶社：纪念碑东南约 170 m（OSM 点位），湖边一组灰瓦开敞茶廊 + 单檐牌坊入口，廊下铺满竹椅色小方块。
- 公园其余区域沿用第一版的绿地与树。

### 6. 文殊院（中轴约 38°，山门朝西南）
- 按 OSM 名称取：山门（天王殿）、三大士殿、大雄宝殿（单檐歇山，高 10.56）、说法堂、藏经楼、文殊阁（多层重檐楼阁）。
  每殿按真实轮廓与朝向建：台基 + 红柱 + 深红花格门窗色带 + 灰瓦歇山/悬山顶。
- 院墙：沿寺院面外围一圈赭黄墙、灰瓦墙帽。
- 千佛和平塔：OSM 点位，六角 11 层、通高 21；六角石台 + 莲花座；塔身暗红嵌金色佛像色块；每层铸铁翘檐；塔刹贴金。

### 7. 合江亭 · 安顺廊桥
- 合江亭：两座六角重檐攒尖亭连体（共 10 柱），金黄琉璃瓦、红柱，坐在 3.5 m 高的花岗岩台基上，汉白玉栏杆、双向台阶；按 OSM 轮廓定位与朝向。
- 安顺廊桥：全长 81、廊宽 6（桥体 14），三孔半圆石拱 + 两个圆形泄洪孔，上部两层红柱木廊、灰瓦歇山顶，中部与两端楼阁更高；按 OSM 桥面轮廓定位与朝向。
- 锦江上一艘游船（红船身、黄顶棚），沿河轻微漂动。

## 验收

- 每个景点一张近景截图（`#/city?spot=N`），与资料照片对照：形制、层数、朝向、配色、标志细节可辨认。
- 一张总览截图：景点模型与城区衔接自然，无悬空、无穿插、无闪烁。
- 预算：7 个景点合计新增三角形 ≤ 20 万、draw call ≤ 12；首帧构建时间增加 ≤ 1 s（SwiftShader 下可放宽）。
- 城市目录 ESLint、Prettier 通过，`yarn build` 成功。

## 暂不包含

- 斗拱、彩画、雕花、匾额文字等微观细节
- 室内、夜景灯光
- 除游船、喷泉外的动画
