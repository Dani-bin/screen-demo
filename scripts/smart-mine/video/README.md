# 智能矿山解说视频

按口播文案自动生成的横屏解说视频（1920 × 1080、30 fps、约 90 秒，无声），配音和字幕在剪映里合成。

## 成品（git 忽略，在 `models/smart-mine/video/out/`）

| 文件               | 用途                                                                                                                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `智能矿山解说.mp4` | 画面：开场是全息扫描（半透明地形里井下巷道发光，一道光带扫过变成真实地表，标注弹出）和大屏出场，正文为三维镜头逐帧录制，外加钻场识别平面动画和说明卡片。画面下方约 180 px 留给字幕 |
| `字幕.srt`         | 63 条短句字幕，时间按口播语速（每秒约 6 个字）排好                                                                                                                                 |

## 导入剪映

1. 导入 `智能矿山解说.mp4` 放到主轨。
2. 文本 → 本地字幕 → 导入 `字幕.srt`，字幕会按时间铺好。
3. 配音任选一种：
   - **文本朗读**：选中全部字幕 → 朗读，选男声。语速调到画面能对上为止，时间轴是按每秒约 6 个字排的，一般在 1.1–1.2 倍。
   - **自己录**：照着字幕念。哪段快了慢了，拖一下那段字幕和画面就行，镜头之间都有 0.5 秒叠化，切点不会生硬。
4. 片尾 81–90 秒是提问定格，适合加评论引导贴纸。

## 重新生成

先启动开发服务器（`.claude/launch.json` 的 `bi-demo`，端口 8893），然后：

```bash
python scripts/smart-mine/video/timeline.py                          # 按文案排时间轴、写字幕
node scripts/smart-mine/video/record.mjs http://localhost:8893       # 逐帧录三维镜头（约 4 分钟，可只录某几个：后面加镜头 id）
python scripts/smart-mine/video/compose.py                           # 合成编码（--preview 秒 只出一帧 PNG，调版式用）
```

- **改文案**：改 `timeline.py` 里的 `SEGMENTS`（`|` 是字幕手动断句点），三步都要重跑。
- **改镜头时长或顺序**：改 `shots.json`（时间写成「口播段 + 段内秒数」，文案变了也能对上）。
- **改运镜**：改 `record.mjs` 的 `SPECS`。
- **改说明卡和平面动画**：改 `compose.py`。

录制原理：脚本停掉页面自己的渲染循环，按虚拟时间逐帧设置镜头、外观和时钟（替换了页面的 `Date.now`，录制时矿区当地时间从凌晨 1:12 开始，延时镜头快进到上午 10:40），渲染一帧截一张图，所以成片是均匀的 30 帧，不受截图速度影响。工业广场镜头的俯角要控制在 38° 以内，否则无头 Chrome 走 GPU 截图会卡住（见 CLAUDE.md）。

需要：Node 22+、Chrome；Python 的 numpy、Pillow、imageio-ffmpeg（自带 ffmpeg）。
