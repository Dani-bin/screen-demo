# 无人机巡检监控平台解说视频

按口播文案自动生成的横屏解说视频：1920 × 1080、30 fps、约 71 秒。视频无声、不烧字幕，字幕是单独的 SRT 文件，配音在剪映里做。做法同智能矿山（`scripts/smart-mine/video/`）。

## 成品（git 忽略，在 `models/drone/video/out/`）

| 文件 | 用途 |
| --- | --- |
| `无人机巡检解说.mp4` | 画面：页面实录，逐帧录制。整屏开场推向泄漏光柱 → 去掉面板飞越罐区、装置区、码头 → 放大机队面板 → 侧看 UAV-02 悬停监视 → 放大机载红外画面 → 放大事件流并点"派单处置" → 放大大风停飞、离线的机场卡片 → 拖动时间轴回放 → 绕装置区近景 → 回到整屏。镜头之间 0.5 秒叠化，右上角注明"演示项目 · 园区与数据均为虚构" |
| `字幕.srt` | 45 条短句字幕，时间按口播语速（每秒约 6 个字）排好 |

## 导入剪映

1. 导入 `无人机巡检解说.mp4`，放到主轨。
2. 文本 → 本地字幕 → 导入 `字幕.srt`，字幕会按时间铺好。
3. 配音任选一种：
   - **文本朗读**：选中全部字幕 → 朗读。时间轴按每秒约 6 个字排，语速一般调到 1.1–1.2 倍能和画面对上。
   - **自己录**：照着字幕念。哪段快了慢了，拖一下那段字幕和画面就行。
4. 字幕默认在画面底部，会压住大屏的时间轴；介意的话在剪映里把字幕挪到画面上方。

## 重新生成

先启动开发服务器（`.claude/launch.json` 的 `bi-demo`，端口 8893），然后：

```bash
python scripts/drone/video/timeline.py                   # 按文案排时间轴、写字幕
node scripts/drone/video/record.mjs http://localhost:8893 # 逐帧录全部镜头（约 6–8 分钟；后面加镜头 id 可只录某几个）
python scripts/drone/video/compose.py                    # 合成编码（--preview 秒 只出一帧 PNG）
```

- **改文案**：改 `timeline.py` 的 `SEGMENTS`（`|` 是字幕手动断句点），三步都要重跑。
- **改镜头时长或顺序**：改 `shots.json`（时间写成"口播段 + 段内秒数"，文案变了也能对上）。
- **改运镜、界面显隐、放大位置**：改 `record.mjs` 的 `SPECS`。
- 抖音封面底图：`record.mjs <地址> --still cover 0 <out.jpg> --dpr 2`（放大视口出 3840×2160，截 JPEG；4K PNG 和 2 倍像素比在无头 Chrome 里会卡死），封面和发布文案见 `docs/design/drone/douyin/README.md`。
- 只录部分镜头时，"派单处置"之后的镜头看不到已派单的状态（点击发生在 dispatch 镜头里），成片请整套重录。

录制原理：脚本停掉页面自己的渲染循环，按虚拟时间逐帧设置时钟（替换页面的 `Date.now`，园区时间从 2026-10-19 14:02:25 开始，泄漏告警正在进行）、镜头和页面放大，渲染一帧截一张图，所以成片是均匀的 30 帧。放大面板时，每帧先去掉页面缩放再渲染，避免机载窗口画错位置。镜头推近时压低灯光晕的透视放大，避免成片的光点糊成白团。

需要：Node 22+、Chrome；Python 的 numpy、Pillow、imageio-ffmpeg（自带 ffmpeg）。
